# 夜糖事务所 · 第四版方案

版本：v3（2026-10-25）
状态：已实施（2026-10-25）；立绘按约定使用剪影占位
范围：基地房间二级菜单、市场日刷新/升级/高级招聘、退休区标签、自定义契约者、立绘服装表情、装备、侵蚀与魔女化、势力与物资、城市安定度、周期 Boss。

---

## 1. 本版新增

在 v2 基础上增加五套相互咬合的系统：

1. 立绘导入支持 PNG，任意尺寸进入实时裁剪；输出立绘与头像。
2. 魔法少女模板增加外貌、性格、服装描述；每名角色有多套服装与六种表情，换装/换表情同时更新立绘和头像。
3. 装备系统：两个槽位，提供数值、被动 buff 与特殊技能；装备来自势力市场。
4. 侵蚀度：三阶段，逐级降低共情、提高其他属性；第三阶段魔女化，必须定期使用魔女势力药物，否则死亡。
5. 势力：魔女、魔法少女协会、市政府；各自在市场供货、在会客厅派驻代表并发布任务。

核心原则：**所有数值只经过一条 `effectiveStats` 管线**，避免服装、装备、侵蚀、势力、安定度各自乘算导致失控。

## 2. 市场

### 2.1 四个标签

```
市场
├── 候选名册  每日 2 位起，1–2 级，00:00 刷新
├── 在职契约  剩余天数、续签、技能池
├── 物资采购  三个势力货架、装备与消耗品
└── 退休区    预置栀子，远程联络/返聘
```

### 2.2 候选刷新与升级

- 市场 Lv.1–4，每日数量 2/3/4/5，升级费 6,000/12,000/24,000。
- 每日 00:00 刷新普通候选，1 级 70%、2 级 30%。
- 自定义角色固定保留 7 天；高级招聘角色保留 3 天；普通候选保留到当日结束。
- 候选池上限 6；满了不再补，提示“今日名册已满”。
- 候选由本地生成器产生，带外貌/性格/服装描述与三技能。
- 立绘使用本地分层人像，不调用外部图片。

### 2.3 高级招聘

- 指定 1–6 级；等级上限 = 市场等级 + 2。
- 每日 1 次；花费 `1,200 × 等级` 星砂，并扣安定度 1/2/4/6/9/12。
- 立即生成该等级候选，加入候选池，不自动签约。
- 确认前展示城市阶段变化。

### 2.4 物资采购

- 按势力分三个货架：月蚀庭、星灯协会、樱雾市役所。
- 每件物资显示：价格、势力声望要求、槽位/消耗品、数值、被动、特殊技能、侵蚀代价。
- 声望价格档：<30 +10%，30–59 原价，60–79 −5%，80+ −10%。
- 库存每 3 天刷新；部分禁忌装备需要魔女声望 ≥40。
- 购买进入事务所仓库；装备在档案“外观与装备”页装配，消耗品在对应界面使用。

### 2.5 退休区

- 市场第四标签，预置栀子 Lv.4（契约到期），退休金 880 / 10 日，欠缴 0。
- 可远程联络（40 星砂/次，每日首次 +1 羁绊）与返聘（600 + 等级×120）。
- 顶部显示退役人数、每 10 日合计退休金、累计欠缴。

## 4. 自定义契约者

### 4.1 入口与限制

- 市场“撰写新契约”；安定度 ≥40 开放。
- 固定 1 级；进入候选池后保留 7 天，仍走签约/容量/资金校验。
- 登记费 300，发布时扣除。

### 4.2 向导（五步）

1. **身份**：姓名、代号、称号、元素、职业、代表色、引语、当前目标。
2. **外貌与性格**：外貌描述 20–120 字、性格描述 20–120 字、默认服装描述 10–80 字。
3. **能力**：四维点数 260，每项 40–90，必须分配完。
4. **技能与特性**：3 技能、最多 3 特性；规则同 v2。
5. **立绘与确认**：上传 PNG → 实时裁剪 → 选择默认服装/表情 → 费用摘要。

### 4.3 点数与费用

- 1 级生命 96 + 共情×0.3。
- 签约金 `1,800 + (四维总和 − 260) × 40 + 技能档位附加`（本职 +300、奥义 +700）。
- 登记费 300；放弃发布不扣。

## 5. 立绘、服装与表情

### 5.1 分层立绘

所有角色使用同一套 `PortraitSpec` 渲染：

```
PortraitSpec {
  kind: 'layered' | 'imported'
  hair, eyes, faceShape, palette
  outfitId, expression, accessories
  variantKey?
}
```

- 分层模式：头发/身体/服装/五官/饰物分层 SVG 组合，动态生成。
- **当前实施阶段先统一使用剪影立绘**：保留 `PortraitSpec` 数据结构与服装/表情切换逻辑，渲染层先输出带轮廓光、发型剪影与元素色的半身剪影；等系统验证完成后再替换为完整分层美术。
- 种子六人：每人 3 套服装（制服/私服/礼装）× 6 种表情，由分层组合产生，不预生成 18 张图。剪影阶段通过轮廓、服装剪影、眼睛与表情符号体现差异。
- 自定义角色：8 种发型、6 种眼型、8 套服装、3 种体型、元素配色。
- 头像不是单独文件，而是同一 `PortraitSpec` 的 1:1 裁剪视图；换装/换表情后头像同步变化。
- 渲染结果按 `specKey` 缓存，避免列表重复计算。

### 5.2 PNG 导入与实时裁剪

- 接受 PNG；同时兼容 JPG/WebP 作为便利。
- 单文件 ≤12MB；源图最短边 <320px 拒绝，320–639px 允许但提示“可能偏软”。
- 上传后进入实时裁剪器：
  - 4:5 立绘框，拖动、滚轮/滑杆缩放 1–4 倍，重置。
  - 右侧实时预览：市场卡、编队小头像、档案大图。
  - 输出立绘 768×960 WebP（带 alpha，质量 0.85）。
- 头像页：1:1 框，默认取立绘上部人脸区域，可独立拖动/缩放；输出 256×256 WebP。
- 所有输出存为 data URL；单角色约 80–140KB；最多 16 个自定义角色。

### 5.3 导入立绘的服装与表情

导入的是单张位图，无法像分层立绘一样任意组合。规则：

- 基础 PNG 绑定“默认服装 + 平静表情”。
- 服装/表情变体需要为每个组合上传一张 PNG；未上传的组合在衣柜/表情栏中禁用，并说明“该组合尚未导入立绘”。
- 每名导入角色最多 6 张变体位图；超出提示先删除旧变体。
- 分层角色不受此限制。

这是本方案唯一的能力差异，必须在界面上明确，不用换色或滤镜伪装成新服装。

### 5.4 表情

- 六种：平静、微笑、惊讶、难过、生气、害羞。
- 档案“外观与装备”页可手动切换，选择持久化到 `Girl.expression`。
- 对话中根据关键词/情绪自动切换；玩家手动选择后保持到下一次自动切换。
- 头像与立绘使用同一表情。

### 5.5 服装

- 每名角色 3 套服装：制服、私服、礼装；各有名称、描述、配色。
- 服装只改变外观，不提供数值，避免与装备叠加。
- 换装在档案中进行，立即更新立绘、头像、市场卡与编队小图。

## 6. 装备

### 6.1 槽位与属性

- 两个槽位：法器（weapon）、护符（charm）。
- 装备提供：
  - 四维数值加成；
  - 被动 buff（战斗开始生效或常驻）；
  - 可选特殊技能（作为第四技能进入战斗）；
  - 可选侵蚀代价（每场战斗 +1–2 侵蚀）。
- 同一角色不能重复装备同一件唯一装备；消耗品不占槽。

## 7. 侵蚀度

### 7.1 三阶段

| 阶段 | 侵蚀值 | 共情 | 其他三维 | 状态 |
| --- | --- | --- | --- | --- |
| 澄明 | 0 | 100% | 100% | 正常 |
| 浅蚀 | 1–39 | −5% | +3% | 轻微异变 |
| 深蚀 | 40–69 | −12% | +8% | 可见异变 |
| 魔女 | 70–100 | −25% | +15% | 转化为魔女 |

- 所有阶段加成进入 `effectiveStats`，不修改基础值。
- 魔女化后 `witch: true`，立绘加角/光环/异色瞳叠加层，头像同步。
- 魔女不能接受协会与市政府任务，只能接战斗与月蚀庭任务；普通对话羁绊获取减半。

### 7.2 增长与降低

- 每场战斗结束 +3；Boss 战 +6；战斗失败额外 +2。
- 每日结算时疲劳 ≥80，+2。
- 宿舍休息一次（90 分钟）−5 侵蚀、−20 疲劳。
- 净化课程 −8；魔女药物不降低侵蚀，只维持生命。
- 侵蚀值上限 100，达到 70 立即触发魔女化剧情与通知。

### 7.3 魔女与药物

- 魔女必须每 **10 日**使用一次“月蚀抑制剂”。
- 药物价格 2,400，月蚀庭声望 ≥20；可囤积，最多 5 支。
- 每日 00:00 自动消耗：若 `drugUntilDay < day` 且仓库有药，自动使用，延长 10 日。
- 无药时进入断药期，最多持续 **10 日**：
  - 断药第 1–3 日：每日 −8 生命；
  - 第 4–6 日：每日 −14 生命；
  - 第 7–9 日：每日 −22 生命；
  - 第 10 日：生命归零，进入纪念墙，死因“断药”。
- **断药期内无法派遣、无法远行、无法接受势力任务**；仍可治疗、休息、对话、购买药物。
- 断药期内使用抑制剂：立即结束断药状态，`withdrawalDays=0`，`drugUntilDay=day+10`。
- 防软锁：魔女且金币 <2,400 时，月蚀庭提供 1 支应急药，代价为月蚀庭声望 −10；每 10 日限 1 次。
- 档案、编队与名册显示“药物剩余 N 日”或“断药第 N 日”；剩余 ≤2 日时顶部警示。

## 8. 势力

### 8.1 三个势力

| 势力 | 定位 | 初始声望 | 货物风格 |
| --- | --- | --- | --- |
| 月蚀庭 | 魔女势力 | 20 | 禁忌装备、抑制剂、高风险高收益 |
| 星灯协会 | 魔法少女协会 | 50 | 治疗、净化、稳健法器 |
| 樱雾市役所 | 市政府 | 45 | 许可、防护、经济与秩序 |

- 势力声望 0–100，与城市安定度分开计算。
- 声望影响价格档、货架解锁、代表任务质量。
- 城市安定度是“市民整体信任”；势力声望是“三个组织对你的态度”。

### 8.2 会客厅代表

- 会客厅第四标签“势力代表”，三张 envoy 卡。
- 每张显示：势力徽记、代表姓名/头衔、当前声望、当日任务、奖励、接受按钮。
- 每个势力每日 1 个任务；接受后进入派遣地图，带势力标签。
- 任务完成：
  - 月蚀庭：声望 +6，城市安定 −2；
  - 星灯协会：声望 +6，城市安定 +2；
  - 市政府：声望 +6，城市安定 +1。
- 任务失败：声望 −3，城市安定按原规则。
- 代表每日轮换一名；不使用完整立绘，使用势力徽记 + 分层剪影，避免额外美术量。

### 8.3 与市场、侵蚀的联动

- 月蚀庭声望 ≥40 解锁禁忌装备；≥55 解锁夜祷指环。
- 星灯协会声望 ≥25 解锁净化课程；≥35 解锁协会徽章。
- 市政府声望 ≥30 解锁怀表；≥45 解锁税补券。
- 魔女化后，协会与市政府代表拒绝发布任务；月蚀庭任务奖励提高 20%。

## 9. 城市安定度与 Boss（沿用 v2）

### 9.1 安定度

- 六阶段：崩坏 0–19、动荡 20–39、维持 40–59、安定 60–74、信赖 75–89、灯火 90–100。
- 影响：招募概率/签约金、每日委托池、队伍共鸣、日常关系。
- 高级招聘与 Boss 是主要消耗口；不做每日自然衰减。

### 9.2 Boss

- 第 16 日 21:00 首现，每 3 日一次。
- 在场每 3 小时 −1 安定；48 小时未击败额外 −6 并离场。
- 3 人编队、90 分钟、6 轮、Boss + 2 随从。
- 胜利 +8 安定、8,000 星砂、60 经验；时间耗尽 Boss 带伤保留；失败保留。
- Boss 战额外 +6 侵蚀。

## 10. 数据模型（v6）

```ts
type Expression = 'calm' | 'smile' | 'surprise' | 'sad' | 'angry' | 'shy';
type FactionId = 'witch' | 'association' | 'government';

interface Outfit {
  id: string; name: string; description: string;
  palette: string[]; layerKey: string;
}

interface Equipment {
  id: string; name: string; faction: FactionId;
  slot: 'weapon' | 'charm';
  price: number; standingReq: number;
  stats?: Partial<Record<StatKey, number>>;
  passive?: string; skillId?: string;
  corruptionPerBattle?: number;
}

interface Girl {
  appearance: string; personality: string; outfitDescription: string;
  wardrobe: Outfit[]; outfitId: string; expression: Expression;
  corruption: number; witch?: boolean;
  drugUntilDay?: number; withdrawalDays?: number;
  equipment: { weapon?: string; charm?: string };
}

interface FactionState {
  standing: number; stockDay: number; envoyDay: number;
  envoyTaskId?: string;
}

interface GameState {
  version: 6;
  factions: Record<FactionId, FactionState>;
  inventory: Record<string, number>;
  marketLevel: number;
  marketDay: number;
  advancedDay?: number;
  boss: BossState | null;
  bossCycle: number;
  nextBossDay: number;
  customSkills: Skill[];
}
```

新增 action：

```ts
| { type: 'changeOutfit'; girlId: string; outfitId: string }
| { type: 'setExpression'; girlId: string; expression: Expression }
| { type: 'buyItem'; itemId: string }
| { type: 'equipItem'; girlId: string; itemId: string; slot: 'weapon' | 'charm' }
| { type: 'useItem'; girlId: string; itemId: string }
| { type: 'acceptFactionTask'; faction: FactionId }
| { type: 'upgradeMarket' }
| { type: 'advancedRecruit'; level: number }
| { type: 'createGirl'; draft: GirlDraft }
```

迁移 v5 → v6：

- 所有角色补 `appearance/personality/outfitDescription` 默认文案。
- `wardrobe` 补三套默认服装；`outfitId` 指向制服；`expression: 'calm'`。
- `corruption: 0`、`equipment: {}`。
- `factions` 初始 20/50/45；`inventory: {}`。
- 移除基地退休房间；市场保留退休标签。
- 旧候选保留；下一次 00:00 起按新规则刷新。

### 10.1 数值管线

```
baseStats
+ levelGrowth
+ equipment.stats
= equippedStats
× corruptionMultiplier
+ factionPassive
+ cityResonance
= effectiveStats
```

- 所有战斗、调查、匹配率、界面显示都读取 `effectiveStats`。
- 服装不参与数值管线。
- 侵蚀的共情削减在装备之后计算，避免装备抵消阶段惩罚。

## 11. 实施阶段

- **P0**：v6 类型、迁移、数值管线、种子角色外观/服装字段。
- **P1**：分层立绘渲染器、3 套服装、6 表情、头像同步、缓存。
- **P2**：PNG 导入、实时裁剪、立绘/头像输出、变体管理。
- **P3**：侵蚀阶段、魔女化、药物、断药死亡、宿舍休息联动。

## 13. 风险

- **美术量**：六名种子角色 × 3 服装 × 6 表情如果逐张绘制会爆炸；必须做分层组合，先做 3 套服装共用层，再补差异件。
- **导入变体**：单张 PNG 无法任意换装/表情；方案选择“按组合上传”，并在界面禁用缺失组合，不用滤镜伪装。
- **存储**：导入立绘 + 变体可能超过 localStorage；用 WebP、单角色 6 变体、总量 16 人、配额提示控制。
- **侵蚀叠加**：侵蚀、装备、势力、安定度都能改数值；必须只走 `effectiveStats`，并在档案显示来源明细。
- **魔女软锁**：无药无钱会导致必死；应急药与月蚀庭任务保底，但仍保留死亡可能。
- **阵营冲突**：月蚀庭任务降城市安定，可能让玩家越做越难；用协会/市政府任务作为对冲，并在代表卡上标明后果。
- **测试迁移**：市场退休区、会客厅、档案页签的旧 ID 需要别名或同步更新。
