# 外观装备页与势力货架 · 实施方案

日期：2026-10-25。范围：纯前端原型，不改后端。目标是把人物档案的“外观装备”页从功能堆叠改成与黑底粉白契约风格一致的可操作界面，并把势力物资改为每日限量货架。

## 1. 问题定位

- 外观装备页缺少专属样式，标题、说明、装备卡沿用浏览器默认字重与行距，和档案其他页的衬线标题、数据字体不一致。
- 侵蚀度放在外观页，和“状态”分离；玩家查看血量/疲劳时看不到侵蚀风险。
- 衣柜与表情混在同一区块，衣柜是横向列表，无法一眼比较三套服装。
- 更换装备使用下拉框，和“从仓库取出、装配”的动作隐喻不符，也看不出仓库里有什么。
- 势力物资无限量购买，只要资金足够就能反复购入同一件装备，削弱每日刷新与声望门槛的意义。

## 2. 设计原则

- **档案是一场仪式，不是一张表单。** 外观页只保留三件事：今天穿什么、此刻是什么表情、身上带着什么。每块都有明确的视觉边界。
- **文字层级统一。** 区块标题用 `--font-display`（宋体/衬线），正文用档案正文，数字、价格、槽位编号用 `--font-data`。不再出现无字距的默认粗体。
- **动作即隐喻。** 衣服用“方格预览”选择；装备用“从仓库拖到身上”装配；不再用下拉框替代动作。
- **风险回到状态页。** 侵蚀是生命状态，不是装饰；放在疲劳值正下方。

## 3. 外观装备页结构

```
[ 01 / 衣柜 ]  最多三套
  ┌────┐ ┌────┐ ┌────┐
  │立绘│ │立绘│ │立绘│   ← 1:1 方格，当前套装粉色描边
  └────┘ └────┘ └────┘
   制服    私服    礼装
   简短描述（一行，超出省略，title 提供全文）

[ 02 / 表情 ]  六种
  平静 微笑 惊讶 低落 生气 害羞   ← 图标 + 文字，单选

[ 03 / 装备 ]  法器 / 护符
  ┌ 法器 ────────┐ ┌ 护符 ────────┐
  │ 蚀月法器      │ │ 空置          │
  │ 魔力 +8       │ │ 从仓库拖入    │
  └───────────────┘ └───────────────┘
  点击任一槽位 → 右侧滑出装备仓库
```

### 装备仓库抽屉

- 从档案右侧滑入，宽度约为档案的 46%，不遮住左侧立绘。
- 顶部两个投放区：法器、护符；当前装备显示名称与被动。
- 下方“仓库中的装备”网格：每件显示图标、名称、数值/被动、持有数量。
- 每件可 `draggable`，拖到对应投放区完成更换；拖错槽位时提示“这件装备不能放入该槽位”。
- 同时保留点击装配作为键盘/触屏回退；点击后立即装配并保持抽屉打开。
- 抽屉内可卸下当前装备；关闭按钮返回外观页。

## 4. 侵蚀度迁移

- 从外观页移除整块侵蚀面板。
- 在“状态概览”的疲劳值下方插入紧凑侵蚀条：阶段名、数值、共情修正、抑制剂/断药状态。
- 保留魔女断药警告与“第 10 日死亡”说明；不在外观页重复。

## 5. 势力货架规则

- 每个势力每天生成 **3 个货位**，可从该势力商品池重复抽取，因此同一天可能出现两件相同物品。
- 每个货位是独立 `stockId`，**只能购买一次**；售出后显示“已售罄”，不随资金恢复。
- 每日 00:00 刷新：清空昨日未售货位，按新一天重新生成 3 个货位；已售出的不保留。
- 声望门槛、价格折扣、抑制剂囤积上限、税补券每 7 日限制继续生效。
- 购买动作从 `itemId` 改为优先使用 `stockId`；保留 `itemId` 兼容旧存档与测试，自动选择该商品今日第一个未售货位。

## 6. 数据与接口

```ts
interface MarketStockEntry {
  id: string;
  itemId: string;
  faction: FactionId;
  sold: boolean;
}

// GameState
marketStock: MarketStockEntry[];

// GameAction
| { type: 'buyItem'; itemId?: string; stockId?: string }
```

- `createInitialState` 生成第 14 日货架。
- `processDay` 在势力 `stockDay < day` 时刷新该势力货架。
- `loadState` 校验 `marketStock`，坏数据回退并补齐当日货架。
- 单元测试覆盖：同物多货位、单货位只能买一次、每日刷新、售罄拒绝、声望/价格仍生效。
- 浏览器测试覆盖：同一物品两个货位、买一个后另一个仍可买、刷新后货位恢复、装备拖入槽位。

## 7. 验收

- 1440 / 1024 / 768 / 390 / 320 无横向溢出。
- 外观页不再出现默认字体；三个区块标题、正文、数字层级一致。
- 状态概览在疲劳值下显示侵蚀度。
- 衣柜最多三格，点击切换后立绘、头像、名册同步。
- 表情与衣柜分区；六种表情可切换。
- 装备槽点击打开右侧抽屉；拖拽与点击都能更换；错误槽位有内部提示。
- 势力物资每个货位只能购买一次，售罄不可点；跨日后刷新。

## 8. 实施结果（2026-10-25）

- 外观页四区块、字体层级、侵蚀迁移、衣柜三格、表情六格、右侧仓库抽屉与拖拽装配均已实现。
- 势力货架改为每势力每日三货位，允许重复物品，每格独立 `stockId`，购买后售罄，跨日刷新。
- 单元测试 30 项通过，其中货架用例覆盖重复货位、单格限购、售罄拒绝与跨日刷新。
- 浏览器测试 21 组通过；新增外观装备页与势力物资两组，覆盖拖拽装配、侵蚀归位与九张货位卡。
- 已知限制：浏览器货架用例只验证一张货位购买后售罄，未强制构造同物双货位；重复货位由单元测试覆盖。
