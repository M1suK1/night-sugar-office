# 夜糖事务所 · 双重审查记录

日期：2026-10-23（初版）、2026-10-24（战斗扩展）。范围：用户确认的纯前端交互原型；未修改工作区其他项目或 DSH 宿主。

## 战斗扩展审查（2026-10-24）

### 功能覆盖

- 七项委托分为战斗与调查；地图可按全部/战斗/调查筛选，显示编队人数与魔物数量。
- 编队支持战斗 3 人、调查 2 人；重复成员、忙碌、退役、低血量与疲劳均有阻断；调查按队伍属性与人数判定。
- 自动战斗严格 15 分钟一轮，洞察随机波动排序、技能加权抽取、命中与伤害、持续效果、护盾、眩晕、治疗；玩家没有战斗指令入口。
- 结局完整：胜利移除委托；时间耗尽击退，获得 80% 收益、魔物回池并带伤；失败保留事件、全队获得疤痕；第五道疤痕死亡。
- 战斗剧场含回放/战报双页、单位血量与共情条、行动顺序、逐轮日志、暂停/倍速/跳过；战报含队伍统计、疤痕与经验。
- 档案四页：状态、能力、关系、心愿；五格疤痕、三技能、七阶关系、退役入口。关系页可跳转同伴档案。
- 魔物图鉴六种几何剪影与完整技能/习性/弱点；纪念墙保留死亡角色与悼词。

### 修复记录

1. `game.ts` 重写后每日经营样本不再更新，跨午夜调查收入只写日志不入账：新增 `sampleFor` 与 `book`，在战斗、调查、雇佣、扩建、治疗处记账，并按事件实际发生日归入。
2. 320px 记录页横向溢出 329px：`.av-battle-row` 五列在窄屏改为三列堆叠。
3. 战斗剧场加宽后与全页截图固定定位拼接产生“半透明”错觉：以视口截图确认面板为不透明；仍将剧场底色改为不透明渐变、提高日志/单位字号与对比度。
4. 战斗窗口同时出现两个关闭按钮：隐藏原生弹窗的通用关闭，保留 `battle-close`。
5. 记录页“累计委托收入/支出”与钱包余额口径不一致：改为“记录期收入/支出”，第三张卡显示当前星砂储备，避免把种子样本当成终身账本。

## 第一轮：正确性与需求覆盖

- 派遣：地图、任务筛选、右侧成员悬停/点击/拖动、指派确认、忙碌/疲劳/生命约束，资金和状态随时间结算。
- 人物：状态、能力、羁绊三页；治疗、休息、交谈、安排派遣均为可操作的界面而非空按钮。
- 基地：完整平面图和成员位置、房间详情、交谈、建设扩容。
- 市场：角色搜索、倾向筛选、档案预览、签约确认、资金与容量限制。
- 记录：收支/声望折线、7/14 日范围、可聚焦数据点、日志过滤和分页。
- 辅助：通知、设置、操作指南、减少动画、自动推进、本地存档、JSON 导出及确认重置。
- 叙事边界：对话界面展示身份、地点、血量/疲劳/羁绊与历史记录；明确注明本地剧情响应，没有真实 LLM 或业务后端。

独立审查发现并已修复：

1. 存档可能包含无对应派遣角色的孤立 active 任务：增加任务与人物的双向一致性校验。
2. 不受约束的人物 ID 可命中原型链键，引发对话崩溃：固定原型角色 ID 白名单；消息容器增加 own-property 和数组防御。
3. 跨午夜推进以终点时间入账，导致午夜前完成的收入记入次日：按剩余时间排序、在每个行动实际完成时刻依次结算，再到达推进终点。
4. 小于一分钟的推进产生无意义成功结果：拒绝小于 1 分钟的请求。
5. 雾眠专属猫咪对白使用 name 与 ID 比较：改为 ID 判断，追加测试。
6. 人物档案采用 tab 语义但缺少方向键行为：增加 roving tabindex、左右循环、Home 与 End 导航，并加入浏览器回归断言。

上述状态缺陷均先以失败测试复现再修复。此前浏览器验收的三处失败为测试假设不正确（治疗后角色已回到会客厅、日期空白、扩建日志使用实际容量文案），已改为校验真实状态与数据。

## 第二轮：质量、无障碍与性能

- TypeScript 严格模式及 noUnused 检查通过；状态行动使用克隆返回，不修改输入状态。
- 游戏界面无外部 alert/confirm；提示由内部 aria-live 区域展示，重置使用自制确认弹窗。
- 使用原生 dialog 的焦点约束；验证 Escape 关闭、回到触发控件；标签页和折线图数据点可键盘操作。
- 存在 main/nav/section/aside/header/footer 等语义区域与跳转主要内容链接；交互控件具有描述性唯一 ID。
- 320 / 390 / 768 / 1024 / 1440 宽度测试；页面无横向溢出；窄屏保留点击派遣替代拖动。
- 支持系统 prefers-reduced-motion 和设置开关；动画以 CSS transform/opacity 为主。
- SVG 城市、人物和字体本地化，无运行时第三方下载；图表使用轻量 SVG 而非外部图表引擎。
- 聊天、日志及经营样本分别限制为每人 60 条、300 条及 60 日；未创建任何远程模型/账号/支付接口。
- 构建产物、node_modules、浏览器截图、环境变量文件与缓存均被 Git 忽略。

## 明确限制

这是前端原型，不是可无限游玩的完整游戏。固定演示任务完成后不再生成，模型响应为本地脚本，没有存档导入、云同步、随机战斗或多人系统。中文标题字体是字形子集，新增文字可能回退到系统字体；没有进行正式 WCAG 认证、屏幕阅读器跨平台验收或 Lighthouse 跑分。
