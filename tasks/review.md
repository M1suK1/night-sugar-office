# 夜糖事务所 · 双重审查记录

日期：2026-10-23（初版）、2026-10-24（战斗扩展）。范围：用户确认的纯前端交互原型；未修改工作区其他项目或 DSH 宿主。

## 战斗扩展审查（2026-10-24）

### 功能覆盖

- 七项委托分为战斗与调查；地图可按全部/战斗/调查筛选，显示编队人数与魔物数量。
- 编队支持战斗 3 人、调查 2 人；重复成员、忙碌、退役、低血量与疲劳均有阻断；调查按队伍属性与人数判定。
- 自动战斗严格 15 分钟一轮，洞察随机波动排序、技能加权抽取、命中与伤害、持续效果、护盾、眩晕、治疗；玩家没有战斗指令入口。
- 结局完整：胜利移除委托；时间耗尽击退，获得 80% 收益、魔物回池并带伤；失败保留事件、全队获得疤痕；第五道疤痕死亡。
- 战斗剧场含回放/战报双页、单位血量与共情条、行动顺序、逐轮日志、暂停/倍速/跳过；战报含队伍统计、疤痕与经验。
- 档案四页：状态、能力、关系、心愿；五格疤痕、三技能、七阶关系、退役入口。关系页可跳转同伴档案。
- 魔物图鉴六种几何剪影与完整技能/习性/弱点；纪念墙保留死亡角色与悼词。

### 修复记录

1. `game.ts` 重写后每日经营样本不再更新，跨午夜调查收入只写日志不入账：新增 `sampleFor` 与 `book`，在战斗、调查、雇佣、扩建、治疗处记账，并按事件实际发生日归入。
2. 320px 记录页横向溢出 329px：`.av-battle-row` 五列在窄屏改为三列堆叠。
3. 战斗剧场加宽后与全页截图固定定位拼接产生“半透明”错觉：以视口截图确认面板为不透明；仍将剧场底色改为不透明渐变、提高日志/单位字号与对比度。
4. 战斗窗口同时出现两个关闭按钮：隐藏原生弹窗的通用关闭，保留 `battle-close`。
5. 记录页“累计委托收入/支出”与钱包余额口径不一致：改为“记录期收入/支出”，第三张卡显示当前星砂储备，避免把种子样本当成终身账本。

### 验证

- `npm test`：19 项状态回归通过，含多选编队、三种战斗结局、跨午夜、疤痕死亡、退役、v1 迁移与坏存档。
- `node tests/browser.mjs`：13 组流程通过，覆盖桌面与 1024/768/390/320。
- 构建通过；战斗剧场 1440 与 390 视口截图人工检查。
- 未实现：LLM 内容生成/工坊、参数化立绘、存档导入、真实后端；战斗日志为本地确定性规则生成。

## 第一轮：正确性与需求覆盖

- 派遣：地图、任务筛选、右侧成员悬停/点击/拖动、指派确认、忙碌/疲劳/生命约束，资金和状态随时间结算。
- 人物：状态、能力、羁绊三页；治疗、休息、交谈、安排派遣均为可操作的界面而非空按钮。
- 基地：完整平面图和成员位置、房间详情、交谈、建设扩容。
- 市场：角色搜索、倾向筛选、档案预览、签约确认、资金与容量限制。
- 记录：收支/声望折线、7/14 日范围、可聚焦数据点、日志过滤和分页。
- 辅助：通知、设置、操作指南、减少动画、自动推进、本地存档、JSON 导出及确认重置。
- 叙事边界：对话界面展示身份、地点、血量/疲劳/羁绊与历史记录；明确注明本地剧情响应，没有真实 LLM 或业务后端。

独立审查发现并已修复：

1. 存档可能包含无对应派遣角色的孤立 active 任务：增加任务与人物的双向一致性校验。
2. 不受约束的人物 ID 可命中原型链键，引发对话崩溃：固定原型角色 ID 白名单；消息容器增加 own-property 和数组防御。
3. 跨午夜推进以终点时间入账，导致午夜前完成的收入记入次日：按剩余时间排序、在每个行动实际完成时刻依次结算，再到达推进终点。
4. 小于一分钟的推进产生无意义成功结果：拒绝小于 1 分钟的请求。
5. 雾眠专属猫咪对白使用 name 与 ID 比较：改为 ID 判断，追加测试。
6. 人物档案采用 tab 语义但缺少方向键行为：增加 roving tabindex、左右循环、Home 与 End 导航，并加入浏览器回归断言。

上述状态缺陷均先以失败测试复现再修复。此前浏览器验收的三处失败为测试假设不正确（治疗后角色已回到会客厅、日期空白、扩建日志使用实际容量文案），已改为校验真实状态与数据。

## 第二轮：质量、无障碍与性能

- TypeScript 严格模式及 noUnused 检查通过；状态行动使用克隆返回，不修改输入状态。
- 游戏界面无外部 alert/confirm；提示由内部 aria-live 区域展示，重置使用自制确认弹窗。
- 使用原生 dialog 的焦点约束；验证 Escape 关闭、回到触发控件；标签页和折线图数据点可键盘操作。
- 存在 main/nav/section/aside/header/footer 等语义区域与跳转主要内容链接；交互控件具有描述性唯一 ID。
- 320 / 390 / 768 / 1024 / 1440 宽度测试；页面无横向溢出；窄屏保留点击派遣替代拖动。
- 支持系统 prefers-reduced-motion 和设置开关；动画以 CSS transform/opacity 为主。
- SVG 城市、人物和字体本地化，无运行时第三方下载；图表使用轻量 SVG 而非外部图表引擎。
- 聊天、日志及经营样本分别限制为每人 60 条、300 条及 60 日；未创建任何远程模型/账号/支付接口。
- 构建产物、node_modules、浏览器截图、环境变量文件与缓存均被 Git 忽略。

## 验证结果

- `npm run build`：通过 TypeScript 与 Vite 生产构建。
- `npm test`：15 项状态回归全部通过，包含跨日、资金/容量、坏存档、危险标识及聊天增长上限。
- `node tests/browser.mjs`：最终复跑 14 组完整浏览器流程全部通过，包含新增的方向键 / Home / End 标签页焦点与选中状态断言；无浏览器错误或失败的资源请求。
- 浏览器使用系统 Google Chrome；构建和 Chrome 启动在当前宿主沙箱中均需要批准的子进程权限，不是应用错误。
- 当前生产资源体积：JS 316.45 kB / gzip 101.28 kB；CSS 87.43 kB / gzip 17.89 kB。不含本地 SVG 和字体；这些不是网络测速或 Lighthouse 分数。

## 明确限制

这是前端原型，不是可无限游玩的完整游戏。固定演示任务完成后不再生成，模型响应为本地脚本，没有存档导入、云同步、随机战斗或多人系统。中文标题字体是字形子集，新增文字可能回退到系统字体；没有进行正式 WCAG 认证、屏幕阅读器跨平台验收或 Lighthouse 跑分。

## 第三版扩展审查（契约、特性、基地与退休）

### 需求覆盖

- 魔法少女模板新增当前目标、特性标签、经验与升级；派遣后按概率显露特性并永久保留。
- 战斗与调查均获得经验；等级上限 10，升级提升主属性与副属性并恢复部分血量。
- 雇佣契约有到期日；到期释放席位并进入退休区，可续签、返聘；欠缴会累积。
- 退休金按等级每日计提，退役成员持续消耗事务所预算；后期多名退役成员会形成真实经济压力。
- 月光诊所提供快速治疗、深度疗养、记忆重塑、复制契约；每项均有价格、状态与次数限制。
- 会客厅可处理成员议题，选择批准、暂缓或驳回，结果影响资源与羁绊；可任命值班助理。
- 星象台可派两人远行，每 60 分钟结算一轮，获得星砂与经验；疲劳到 95 自动返程。
- 市场退休区显示退休金、欠缴与返聘入口；远程手机联络有独立横幅、计费与每日羁绊上限。
- 地图增加战斗/调查筛选、推荐等级、编队人数与魔物数量；新增一键编队入口。

### 独立检查与实测

- `npm run build`：通过 TypeScript 与 Vite 生产构建。
- `npm test`：29 项状态回归全部通过，新增经验升级、退休金与欠缴、远程联络、续签/复制、星象台、会客厅议题。
- `node tests/browser.mjs`：16 组浏览器流程全部通过，新增契约成长页、基地议事与远行、退休区远程联络；无控制台错误或失败资源请求。
- 320px 记录页横向溢出已修复；档案页改为桌面内部滚动 + 固定操作栏、手机整页滚动；390px 下标签一度被 flex 压缩到 1px，已用 flex-shrink 修复。
- 视觉复核：桌面档案的目标/特性/契约/诊所两栏同屏；手机档案可完整滚动；基地议事与远行卡片、退休区远程通话均使用既有黑粉视觉系统。

### 数值与限制

- 退休金实现为 `240 + 等级 × 160` 星砂 / 10 日，比方案初稿更直观；欠缴按日累计。
- 续签为 `800 + 等级 × 220 + 羁绊 × 8`，返聘为 `600 + 等级 × 120`；与方案草稿的指数公式不同，以代码为准。
- 远行每 60 分钟一轮，收益含等级、洞察与随机见闻；疲劳 95 自动返程。
- 所有对话仍为本地关键词响应，没有真实 LLM；复制契约生成同一立绘的换色变体，不生成新美术。

## 第四版：市场、势力、侵蚀与自定义契约者

日期：2026-10-25。范围：纯前端原型 v6；未修改工作区其他项目或 DSH 宿主。

### 覆盖检查

- **市场四标签**：候选名册、在册契约、势力物资、退休区均可切换；市场等级 1–4 决定每日候选数，升级费用 6,000 / 12,000 / 24,000；高级招募每日 1 次，等级上限为市场等级 +2，消耗 `1,200 × 等级` 星砂与对应安定度。
- **自定义契约者**：五步向导覆盖身份、能力、技能、特性、立绘；260 点可分配，技能按 tier 限制，特性最多 3 个；PNG 导入支持预览、目标框与缩放滑杆；登记后进入候选名册，固定 1 级。
- **基地二级菜单**：四个房间都打开房间弹窗；会客厅四页（议事/成员/物资/势力代表）可用，诊所与宿舍提供快捷照护，星象台保留远行；势力代表每日任务可接受并进入地图池。
- **装备与外观**：法器/护符两槽；外观页固定三格衣柜、六格表情，点击装备槽从右侧打开仓库抽屉，可拖拽或点击装配；`effectiveStats` 统一供战斗、档案与推荐等级使用。
- **势力物资**：每个势力每天三个货位，可重复同一物品；每个货位只能购买一次，售罄后禁用，次日 00:00 刷新；购买校验声望门槛、月蚀药物上限与税收券限购。
- **侵蚀**：三阶段阈值 1–39 / 40–69 / 70–100；共情 −5/−12/−25%，其余 +3/+8/+15%；战斗、Boss、失败与日结算高疲劳增长；宿舍休息 −5；侵蚀度在状态概览疲劳值下方；魔女药物每 10 日、最多囤 5 支。
- **断药**：最长 10 日，伤害 −8/−14/−22 分段递增，第 10 日死亡；断药期间禁止派遣、远行与势力任务，顶部与档案均有警示；抑制剂立即解除。
- **势力与安定**：三势力声望独立；市场折扣、每日委托数量、编队契合接入安定度；Boss 第 16 日出现，在场每 3 小时 −1 安定，48 小时额外 −6，可从上图直接编队。
- **剪影立绘**：种子角色与差分统一渲染剪影；服装色、表情、魔女角与侵蚀纹理可辨；导入 PNG 显示原图并按裁剪参数生成头像。

### 验证

- `npm run build`：通过 TypeScript 与 Vite 生产构建；CSS 171.26 kB / gzip 33.49 kB，JS 512.44 kB / gzip 164.80 kB。
- `npm test`：30 项状态回归全部通过；覆盖 v6 初始数据、断药禁派、装备属性、市场升级与高级招募、每日货位限购与刷新、自定义登记、势力任务、Boss 周期。
- `node tests/browser.mjs`：22 组流程全部通过，新增外观装备页、势力物资与完成委托回看战斗记录三组；桌面、1024、768、390、320 均无横向溢出，无控制台错误。
- 视觉复核：外观页四区块与字体层级统一；衣柜三格、表情六格；装备抽屉在桌面右侧滑入、手机全屏；市场货架三列分组，售罄状态明确；战斗行动日志为每次命中/伤害/治疗追加可复算公式行（敏捷差、d100、魔力×倍率×波动、护盾与减伤）。

### 明确限制

- 本版立绘是功能占位剪影，不是最终美术；换装与表情只改变剪影配色、轮廓和眼部符号。

- 势力物资、装备与 Boss 均为固定演示数据，没有随机生成或真实 LLM 内容包。
