# 夜糖事务所 · 前端原型实施计划

## 已确认范围
2026-10-23 用户确认「按方案制作」：独立 React + TypeScript + Vite 前端，不实现任何后端，不修改工作区其他项目。

## 设计判断
以午夜城市派遣沙盘为唯一视觉焦点。拒绝普通指标卡片后台：中央是手绘式都市街区、河道、任务信标与魔法航线；右侧为可拖动角色档案，左侧为窄幅站点导航。黑色、粉色、白色主调，少量冰蓝用于异象与水系。猫、糖果与星星以线性图标、街区标识和角色契约印章进入功能，而不是 emoji。

配色：墨黑 #0B0B10，雾白 #F5F0F2，蔷薇粉 #F49ABD，糖霜粉 #FFD6E5，冷灰 #85828F，冰蓝 #9CC9D2。字体：中文展示标题用 Noto Serif SC/本机宋体回退；中文界面 Noto Sans SC/微软雅黑；数据 Space Grotesk/等宽回退。避免大面积渐变与无意义光晕。

## 架构与文件范围
- src/game.ts：纯函数状态模型、内置人物/任务/设施数据、行动规则、时间结算、存档校验。
- src/App.tsx、src/components/：布局、地图、侧栏、人物档案、任务弹层、对话、内置通知、设置。
- src/views/：基地、市场、记录等页。
- src/styles.css：设计 token、响应式和 reduced-motion。
- public/art/：自主制作本地 SVG 都市沙盘及人物插画。
- tests/game.test.ts、tests/browser.mjs：状态测试和浏览器交互验收。
- package.json、tsconfig.json、vite.config.ts、index.html：纯前端工具链。

## 任务与验收
1. 工程与状态测试：派遣资格、重复派遣、时间结算、治疗休息、资金不足、容量限制、雇佣去重、坏存档回退均有测试。先运行失败测试，再实现状态逻辑。
2. 派遣主界面：顶端时间/天气/资源；中央地图任务可点击、角色可拖动派遣；右栏角色悬停信息和档案详情完整。键盘和触屏可使用点击替代拖动。
3. 人物与剧情：档案显示能力、血量、疲劳、技能；治疗休息有时间成本；自由输入与固定选择可推动本地剧情，明确不宣称真实 LLM 已接入。
4. 基地：平面图标注房间与闲置角色；房间操作、对话、建造和扩容可操作，资金及容量联动。
5. 市场：候选角色完整档案、筛选、雇佣确认和约束。
6. 记录：操作日志、经营折线图、时间范围和指标切换；可观察操作带来的变化。
7. 审查：构建、状态测试、浏览器主流程、320/768/1024/1440 布局、无重复 ID、无控制台错误、dialog 焦点约束、可减少动画。

## 边界
处理：资金不足、人员忙碌或过劳、任务重复、容量不足、输入为空、本地存储损坏或不可写、刷新恢复、关闭弹层回焦、触屏替代操作。
不处理：真实模型请求、账号、云端保存、服务端战斗、付费、多人和外部通知；均超出纯前端原型范围。
