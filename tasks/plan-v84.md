# v84 势力代表委托改成三种玩法

## 一、要改成什么样

每次换日，每个势力给出**一份**委托，但内容从现在的「固定一条中危战斗」变成**三种之一**：

| # | 类型 | 玩法 | 好感 | 额外收益 | 其他 |
| --- | --- | --- | --- | --- | --- |
| 1 | 共建委托 | 在该势力**自己的辖区**上完成一条委托（模板生成） | **+1** | 星砂 **+10%** | — |
| 2 | 破坏行动 | 去**别的势力辖区**打一场魔法少女对战（对方 1–3 人） | 破坏方 **0**，被破坏方 **−3** | 星砂 **+50%** | 两势力**火气值上升** |
| 3 | 借调 | 把已契约的少女借给该势力 **1–6 小时** | **+1** | 收益 = 该少女在星象台的**每小时收益 × 时长**，**不加疲劳** | 借调期间不能派遣 |

不变的部分：每天每势力一份、接下后进城市地图/派遣流程、次日换新。

## 二、可复用的现成机制（省掉大半工作量）

| 需要的能力 | 现成实现 |
| --- | --- |
| 委托模板池 / 辖区 / 难度 / 判定 | `src/rules/missions.ts`（`baseCommissionPool`、`annotateMission`）、`districtAt` |
| 「对面真的是魔法少女」的战斗 | `interceptionFor()`（`src/rules/battle.ts`）已经会从势力名册里挑 **1–3 名**少女当敌人，`simulateBattle(battleKind: 'interception')` |
| 势力好感 | `state.factions[f].standing`（现有 ±clamp 逻辑在 `battle.ts`） |
| 火气值 | `src/hostility.ts`：`applyHostility(state, [{ pair, delta, reason }])`，档位/开战全在这套里 |
| 每小时结算 | `advance()` 里已有「每 60 分钟结算一次」的循环（星象台用的），借调可以挂同一个循环 |
| 辖区转移/归属 | `shiftTerritory()`、`state.territories` |

## 三、数据模型

```ts
// 每天每势力一条候选（换日清空，和现在的 envoyTaskId 同生命周期）
type EnvoyOffer =
  | { kind: 'coop'; faction: FactionId; mission: Mission }                    // 已按模板生成
  | { kind: 'raid'; faction: FactionId; target: FactionId; mission: Mission } // mission.interception 已填好
  | { kind: 'loan'; faction: FactionId; hours: 1 | 2 | 3 | 4 | 5 | 6; rate: number };

state.envoyOffers: Partial<Record<FactionId, EnvoyOffer>>   // 换日重掷
state.loans: { id, girlId, faction, rate, startedAt, endsAt }[]  // 借调中的少女
```

- `Mission` 增加两个字段：`envoyKind?: 'coop' | 'raid'`、`envoyFaction?: FactionId`（`raid` 再记 `envoyTarget`），结算时据此分支。
- 借调不进 `Mission`：它没有战斗。少女状态暂时沿用 `expedition`（`roomId` 记星象台），并在少女上记 `loan?: { faction, until }`，界面标签改成「借调中 · 星灯协会」。
  - 备选：新增 `GirlStatus = 'lent'`。代价是 30 处 `status === 'expedition'` 的引用都要过一遍，第一批不做，等三批跑完再评估。

## 四、生成规则（换日时跑一次）

1. 每个势力先按权重掷一种类型：共建 45% / 破坏 30% / 借调 25%（权重进 `balance.ts`）。
2. 可行性兜底，避免给出做不了的选项：
   - **破坏**：目标势力必须是「不是自己」且在该势力辖区里有名册（`rosterMembers`）；否则退共建。
   - **借调**：至少 1 名空闲少女；否则退共建。
   - **共建**：自己辖区优先；若自己没有任何辖区（全部被夺），也退成「在自己控制的任意辖区」或直接给破坏。
3. 三天内不重复同一类型（记 `lastKinds[faction]`），避免连着三天都是借调。
4. 共建/破坏的委托从模板池取：`difficulty` 按该势力当前好感分档（≥60 中危、≥30 高危），`district` 必须是**该势力自己**的辖区（共建）或**目标势力**的辖区（破坏）；报酬基数 ×1.10 或 ×1.50。

## 五、结算

### 1. 共建（coop）

- 完成（胜利）：`standing += 1`（**注意：不再是 +6**），星砂按 ×1.10 发；失败：`standing -= 1`。
- 不再触发辖区转移（自己辖区完成任务没有归属变化）。

### 2. 破坏（raid）

- 战斗对象：目标势力名册里的 1–3 人（复用 `interceptionFor` 的挑人逻辑，但**强制**指定为目标势力）。
- 胜利：
  - 被破坏势力 `standing -= 3`；发起方 `standing` 不变（你只是拿钱）。
  - `applyHostility`：两势力 **+6~+10**（数值进 balance，默认 +8），理由写「有人在他们的辖区里被打了一顿」。
  - 星砂 ×1.50。
  - 若目标辖区的当前归属就是被破坏势力：**不转移**（破坏不是占领），但该辖区污染 +3、安定度 −2。
- 失败：自己这边不扣好感，但目标势力的火气照加（+4），并额外扣 1 点城市安定。

### 3. 借调（loan）

- 选人 1 名 + 时长 1–6 小时（滑块或按钮组）。
- 每小时收益 = `EXPEDITION_GOLD_PER_HOUR + (星象台等级 − 1) × expeditionGoldPerLevel`（与星象台同一口径，当前是 300 / 350 / 400 / 450）。
- 结算：接下的瞬间**先付全款**（时长 × 每小时收益），少女立刻进入「借调中」，到点自动回岗；**不加疲劳、不涨经验、不触发星象台见闻**。
- 好感 `+1`（接下的那一刻结算，不等回岗）。
- 借调期间不能派遣、不能治疗、不能被再次借出；同一势力同时在借的少女数不设上限，但只能一单（每天一份）。

## 六、界面

- **会客厅 → 势力代表**：一张卡三种形态——
  - 共建：辖区名 + 难度 + 时长 + 报酬（标「+10%」）
  - 破坏：目标势力 + 对方人数区间 + 火气预估（「与星灯的火气 37 → 45」）+ 报酬（标「+50%」）+ 红色风险条
  - 借调：收益公式预览 + 「1–6 小时」按钮组 + 少女选择器（只列空闲的）
- 接下后：共建/破坏进城市地图（现有派遣流程）；借调直接结算，卡片变成「借调中 · 剩余 N 小时」。
- 势力档案页的「代表委托」区块同步显示这三种类型与当前好感变化预览。

## 十、已定（2026-11-05）

1. **破坏的火气按对方辖区状态加权**：基础 +8，再按目标辖区**污染**与**安定度**放大——
   `delta = round((8 + 污染档位×2) × (1 + (60 − 安定度)/60))`，夹在 4–20；
   辖区越脏、越乱，这一场打得越响。
2. **借调允许连续借同一个人**：没有冷却，同一天可以反复借（但每个势力每天仍只有一份委托）。
3. **不要好感补偿**：共建/借调就是 +1 好感，不再额外给 +5 城市声望。
4. **旧 envoy 委托直接换掉**：不做迁移，旧存档里已接下的 `envoy-<势力>-<日>` 按下不表（结算时按旧规则走完即可），
   换日之后一律用新三选一。
5. **UI：每张势力任务卡左侧加势力首领头像**（用当前首领的立绘/头像，与势力档案页同一个来源）。
