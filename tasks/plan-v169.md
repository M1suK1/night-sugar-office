# 方案 v169 · 自定义魔法少女起草：被动改由本地掷骰

## TASK

自定义魔法少女走「让使魔补全」时，技能直接采用模型输出；提示词把 18 条被动整份列给模型，还写着「最多 1 条被动」，结果每次起草都带一条被动。
要求是随机决定带不带（沿用候选生成的三成概率），不是必带。

## APPROACH

模型只负责挑三条主动；带不带被动在起草完成后由本地掷一次骰子决定。掷中时把较弱的一格（基础 → 本职 → 奥义）换成同流派被动，本流派优先、其次通用。
夜间提案候选不在本次范围。

## FILES

| 文件 | 改动 |
| --- | --- |
| `src/skills.ts` | 新增 `rollPassiveSkill`；`pickCandidateSkills` 加 `withPassive` 开关，起草补位时只抽主动 |
| `src/llm.ts` | 起草提示词只列主动、去掉「最多 1 条被动」；模型给的被动一律丢弃；结尾掷骰决定是否换被动 |
| `tests/v169.test.ts` | 掷骰概率、换位规则、提示词不含被动、模型塞被动被丢弃 |
| `package.json` | 测试列表加入 `tests/v169.test.ts` |
| `tasks/todo.md` | 记 v169 |

## EDGE IN

- 模型返回重复、非法、被动 id：都过滤，缺位用 `pickCandidateSkills(seed, element, false)` 只补主动。
- 三条主动里已经有被动：不再叠第二条。
- 元素没有专属被动：落到通用被动。

## EDGE OUT

- 夜间提案候选与魔物的技能仍走 `takeOnePassive` 封顶（用户确认不改）。
- 手动建人路径不变：玩家自己挑，最多 1 条被动。
- 不新增存档字段，不需要迁移。

## ASSUME

- 「随机」沿用 v164 的三成概率，与 `pickCandidateSkills` 一致。
- 起草本身每次由模型重新生成，掷骰不需要可复现。
