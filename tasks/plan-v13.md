# v13 每个生成任务独立绑定预设与任务标签页

## 目标

上一版把提示词按九种用途拆开，但预设仍只有「角色对话 / 结构化生成 / 故事」三档绑定。每日提案与角色起草共用一档，四类剧情共用一档，想给某一种任务单独换语气时仍会牵连其他任务。本版把绑定拆到每个任务，并把预设编辑器改成按任务分页，默认预设直接以任务命名。

## 数据模型

```ts
type PromptTask = Exclude<PromptScope, 'shared'>;
type PresetBinding = Record<PromptTask, string>;
```

八个任务键：

- `chat`：角色对话
- `daily`：每日提案
- `profile`：角色起草
- `storyline`：故事线
- `event`：私人事件
- `arc`：完整剧情
- `incident`：突发事件
- `outfit`：服装词条

共用词条没有独立绑定，始终跟随当前任务所用预设注入。

## 迁移

读取 `night-sugar:preset-binding` 时兼容旧结构：

| 旧键 | 拆给 |
| --- | --- |
| `chat` | `chat` |
| `generate` | `daily`、`profile`、`outfit` |
| `story` | `storyline`、`event`、`arc`、`incident` |

任务键自己的值优先；缺少任务键时回退到旧键；两者都没有才用默认预设。写入时统一保存新结构，因此迁移只发生一次。

## 交互

- 预设编辑器顶部改为十个任务标签页：共用、角色对话、每日提案、角色起草、故事线、私人事件、完整剧情、突发事件、服装词条、全部词条。
- 任务页进入聚焦模式：隐藏左侧预设列表，只显示该任务当前绑定的预设；顶部下拉直接改绑该任务，改绑不会影响其他任务。
- 共用 / 全部词条页保留左侧预设列表，并用顶部下拉选择当前编辑对象。
- 每个任务默认有一份以任务命名的可编辑预设，名字分别是「角色对话」「每日提案」「角色起草」「故事线」「私人事件」「完整剧情」「突发事件」「服装词条」。
- 首次升级执行一次 `ensureTaskPresets`：内置预设按任务各复制一份；旧版共用的「… 副本」由同组第一个任务原地接管并改名，其余任务再复制，保留原副本的接口、正则与词条编辑。
- 迁移标记 `night-sugar:task-presets-v1` 保证只拆一次，不会在用户改绑后再次覆盖。
- 设置页从某个任务入口打开内置预设时，只复制并改绑当前任务。
- 「共用词条」入口复制内置预设时，只改绑原本指向该内置预设的任务，不会把其他任务一起拉过来。
- 删除正在被绑定的预设时，仍把这八个任务回退到各自的默认预设。

## 已知边界

- 共用词条不单独绑定；它属于预设，跟随该预设被哪个任务使用。
- 预设词条仍不能绕过代码契约；枚举、目录 ID、预算、数量继续由代码校验。
