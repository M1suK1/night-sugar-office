# v13 每个生成任务独立绑定预设

## 目标

上一版把提示词按九种用途拆开，但预设仍只有「角色对话 / 结构化生成 / 故事」三档绑定。每日提案与角色起草共用一档，四类剧情共用一档，想给某一种任务单独换语气时仍会牵连其他任务。本版把绑定拆到每个任务。

## 数据模型

```ts
type PromptTask = Exclude<PromptScope, 'shared'>;
type PresetBinding = Record<PromptTask, string>;
```

八个任务键：

- `chat`：角色对话
- `daily`：每日提案
- `profile`：角色起草
- `storyline`：故事线
- `event`：私人事件
- `arc`：完整剧情
- `incident`：突发事件
- `outfit`：服装词条

共用词条没有独立绑定，始终跟随当前任务所用预设注入。

## 迁移

读取 `night-sugar:preset-binding` 时兼容旧结构：

| 旧键 | 拆给 |
| --- | --- |
| `chat` | `chat` |
| `generate` | `daily`、`profile`、`outfit` |
| `story` | `storyline`、`event`、`arc`、`incident` |

任务键自己的值优先；缺少任务键时回退到旧键；两者都没有才用默认预设。写入时统一保存新结构，因此迁移只发生一次。

## 交互

- 预设编辑器底部显示八个独立下拉，替换原来三个。
- 设置页从某个任务入口打开内置预设时，只复制并改绑当前任务。
- 「共用词条」入口复制内置预设时，只改绑原本指向该内置预设的任务，不会把其他任务一起拉过来。
- 删除正在被绑定的预设时，仍把这八个任务回退到各自的默认预设。

## 已知边界

- 共用词条不单独绑定；它属于预设，跟随该预设被哪个任务使用。
- 预设词条仍不能绕过代码契约；枚举、目录 ID、预算、数量继续由代码校验。
