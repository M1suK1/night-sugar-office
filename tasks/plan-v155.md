# 方案 v155 · 角色详情七页重排（战斗 / 描述分组）

> 注：v154 是控制台方案（尚未实施），本方案单独编号，不依赖它。

## 一、现状问题

- **状态概览**一页塞了身体、成长、叙事：血量→经验→目标→特性→疤痕→简介→性格→整块故事线→位置。
- **魔法能力**只有技能和四维，偏空；「有效能力」却在外观页，加点在成长页，装备和物资在外观页——**战斗相关的东西散在四页**。
- **外观装备**同时装「她的样子/说话方式」和「装备/物资」，两类东西混在一页。
- **心愿与羁绊**最空，且和关系页、概览页各重复一半。
- 重复项：当前目标 ×3、经验/等级 ×2、特性 ×2、状态 ×2、疤痕 ×2、羁绊 ×2、简介 ×2。

## 二、目标结构（7 页）

按「她现在怎么样 / 她能打什么 / 她和谁 / 她经历过什么 / 她怎么长大 / 她是什么样的人 / 她想要什么」分组。

| 页签 | 只放这些 | 从哪来 |
| --- | --- | --- |
| **状态概览** | 血量 / 心防 / 疲劳 / 侵蚀（含抑制剂）/ 当前状态 / 疤痕轨道 / 所在位置 | 概览 |
| **战斗能力**（战斗全部集中） | 四维 + **有效能力（并排对比）** + 技能卡 + **属性点加点** + **装备** + **随身物资** | 能力页 + 外观 05 + 成长加点 + 外观装备/物资 |
| **关系网络** | 羁绊环 + 七阶图例 + 同伴关系 +「被记住的片刻」 | 关系 + 心愿 |
| **角色故事**（新页） | 三段槽位 + 回忆 + 当前节拍/蓝图 + 开始/生成/编辑 | 概览里的整块故事线 |
| **契约成长** | 等级 + 经验进度 + 特性卡 + 契约/退休金 + 月光诊所 | 成长（去掉目标与加点） |
| **人物描述**（原外观） | 简介 / 外貌 / 服装文本 / 语料（说话方式·习惯·例话）/ 性格（含编辑）/ 衣柜 / 表情 | 概览的简介与性格 + 外观的文字与衣柜表情 |
| **她的心愿** | 当前目标 / 心愿（quote） | 心愿 + 概览与成长里的目标副本 |

排布顺序：状态 → 能力 → 关系 → 故事 → 成长 → 描述 → 心愿。

- 战斗相关（四维、有效能力、技能、加点、装备、物资）全部收进「能力」，不用来回翻页。
- 人物描述（简介、外貌、服装、语料、性格、衣柜、表情）全部收进「人物描述」，和数值彻底分开。
- 成长只留「升级、解锁、契约、诊所」；心愿只留「目标与心愿」。

## 四、实现方式

- 只搬 JSX 块，不改数据结构、action、存档；`CharacterDialog.tsx` 不新增状态。
- 页签表：
  ```ts
  const dossierTabs = [
    { id: 'overview', label: '状态概览' },
    { id: 'ability', label: '战斗能力' },
    { id: 'relations', label: '关系网络' },
    { id: 'story', label: '角色故事' },
    { id: 'growth', label: '契约成长' },
    { id: 'appearance', label: '人物描述' },
    { id: 'memory', label: '她的心愿' },
  ];
  ```
  保留原 id，只新增 `story`；中文标签统一四字。
- 现有元素 id 全部保留（`#girl-allocate`、`#dossier-equipment-weapon`、`#dossier-story-start`、`#dossier-personality-edit` 等），只换所在页。
- 装备抽屉（`.equipment-drawer`）仍在弹窗根部，不随页签切换。
- 7 个四字标签（约 40px × 7 + 间距）在 558px 宽内放得下；窄屏沿用 `overflow-x:auto`。

## 六、边界

### EDGE IN
- 候选者：没有故事/关系/加点时保持空态。
- 退休 / 离开 / 死亡：页签结构不变，成长页与能力页的锁定逻辑照旧。
- 故事四种状态（无蓝图 / 有蓝图 / 进行中 / 有回忆）都能在故事页显示。
- 窄屏：7 个页签横向滚动。

### EDGE OUT
- 不改字段、action、存档与提示词。
- 不重做视觉风格，只调页签与内容归属。
- 不做「概览小卡跳转」之类的快捷入口。

## 七、待确认

1. **「特性」放哪？** 我建议留在「成长」：它是长期解锁记录，卡面已经写了战斗效果；能力页只放「此刻能打什么」。如果你认为特性也算战斗，就把它挪进能力页。
2. 页签名统一为四字：状态概览 / 战斗能力 / 关系网络 / 角色故事 / 契约成长 / 人物描述 / 她的心愿。
3. 7 页可以吗？（若坚持 6 页，只能把「故事」并进「心愿」，或把「心愿」并进「描述」）
