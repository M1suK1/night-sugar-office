# 夜糖事务所 · 第三版扩展方案

版本：v3（2026-10-25）
状态：**已实现并通过验收（见文末实施结果）**
范围：目标与特性、会客厅议事、星象台远征、诊所的恢复/记忆清除/克隆、10 级上限与一键派遣、难度经验、雇佣合同、退休金与远程联络。

v2 变更：经验改为「两次同推荐等级战斗或四次调查升一级」；新增雇佣期、续签、退休区与返聘；确认全部关键取舍。
v3 变更：新增退休金与欠付机制、退休区远程联络。

---

## 0. 一句话方案

让「目标、特性、当前状态」成为角色的三张叙事标签：LLM 与议事厅用它们决定某个人会提出什么意见、会被什么事件吸引；星象台把闲置角色转成稳定但缓慢的资源；诊所提供止损（治疗、清除记忆）与加速（克隆）；等级、推荐等级与雇佣合同把前两者接进派遣节奏。战斗规则本身不改。

## 1. 现状与改造边界

### 1.1 已有基础

- `src/types.ts`：`Girl` 已有等级、经验、四维、羁绊、疤痕、同伴关系、状态；`GameState` 版本为 3。
- `src/game.ts`：`advance` 已能按真实完成时刻逐件结算，支持跨日；`care` 只有治疗与休息；`loadState` 有严格白名单与 v1 迁移。
- `src/views/AuxViews.tsx`：基地是「平面图 + 房间详情」，会客厅与诊所都走同一个 `RoomDialog`。
- `src/components/CharacterDialog.tsx`：四页档案，尚无目标、特性、持续状态与经验条。
- `src/components/MissionDialog.tsx`：已有编队与契合度，没有推荐等级与一键编队。

### 1.2 本轮不改

- 战斗引擎的命中、伤害、技能权重与结局规则。
- 玩家不可干预战斗的边界。
- 纯前端、无后端、无真实模型调用。
- 现有手工 SVG 立绘与城市资产。

### 1.3 一个必须先补的缺口

当前 `girl.exp` 会因战斗与调查增长，但没有任何升级逻辑，等级是种子数据里的固定值；`Girl` 也没有合同到期日。等级上限、记忆清除、续签与克隆都依赖「可重算的成长与到期日」，所以 P0 必须先补等级与合同字段，其他功能才有稳定地基。

## 2. 数据模型 v4

### 2.1 Girl 新增字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `baseStats` | 四维 | 1 级基础值。升级、记忆清除、克隆都从它重算，避免反复加减出错 |
| `goal` | 文本 | 当前目标，一句话，给玩家看也给 LLM 看 |
| `goalKind` | 枚举 | 寻人、赎罪、求知、守护、归乡、成名、报恩、自由、爱意、空白 |

| `conditions` | 状态数组 | 当前 buff/debuff，含来源、剩余分钟、是否可被诊所移除 |
| `cloneOf` | 角色 id，可选 | 克隆体标记，用于禁止克隆的克隆、纪念与 UI 标注 |
| `generation` | 数字，可选 | 0 为原体，1 为第一代克隆 |

| `contractRenewals` | 数字 | 已续签次数，用于档案履历与提示 |
| `retiredReason` | 枚举，可选 | `contract` 合同到期、`injury` 主动退役；死亡走纪念墙，不进入退休区 |
| `pensionMissed` | 数字 | 连续欠付退休金的天数，用于退休区提示与关系变化 |

### 2.2 GameState 新增字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `assistantId` | 角色 id，可选 | 当前助手；只能从在职、未死亡角色中选择 |
| `opinions` | 意见数组 | 当日意见与历史决定，最多保留 40 条 |

### 2.3 其他类型扩展

- `GirlStatus` 增加 `'expedition'`（星象远征中）。
- `Mission` 增加 `recommendedLevel`（推荐等级，1–10）。

- `ContentPack.schemaVersion` 升到 3，增加 `traits`、`opinionTemplates`、`expeditionNames` 三个可选目录；种子包同步补齐。

- 一键派遣不新增行动类型：界面先算出队伍，仍走现有 `dispatch`，便于测试和二次确认。

## 3. 目标、特性与当前状态

### 3.1 目标

每个角色只有一个当前目标，显示在档案标题下方与议事厅意见卡上。

- 初始目标由种子包给定，例如「找到失踪的姐姐」「还清家里的债」「证明自己不是灾星」。
- 目标不是永久不变：死亡事件、记忆清除、关系达到爱意、完成特定委托时可以更换；更换写入日志，并在档案里保留「目标轨迹」。
- 给 LLM 的输入包含：目标、目标类型、最近一次目标变化、相关角色与地点。
- 目标不直接加减数值，它影响事件权重与意见主题。例：目标为「寻人」的角色更容易接到失踪类委托，也更容易提出外出调查的意见。

### 3.2 特性

**获取**：每次派遣结算后（战斗胜利、击退、失败，调查成功或失败），每名参战角色获得 1–2 个新特性。用战斗种子或「日期 + 角色 id + 委托 id」派生随机，保证同存档可复现。已拥有的特性不重复；达到 8 个后不再新增，但可以替换最旧的一个（界面提示）。

**倾向**：正面 / 负面 / 中性，比例约 40% / 35% / 25%。特性是「倾向」，不是纯好坏：负面特性也能触发专属剧情与 LLM 事件。

**标签**：每个特性带 2–4 个标签，例如 `猫`、`夜`、`甜食`、`洁净`、`恐惧`、`执念`、`人群`、`钟声`、`星象`。这些标签是事件生成器的检索键。

**示例目录**（种子 24 条，可扩展）：

| 特性 | 倾向 | 标签 | 叙事影响 |
| --- | --- | --- | --- |
| 猫缘 | 正面 | 猫、夜、温柔 | 猫类事件更愿意靠近她 |
| 甜食依赖 | 中性 | 甜食、压力 | 高压后更可能提出去糖果街 |
| 洁癖 | 负面 | 洁净、强迫 | 脏乱场景会降低她的耐心 |
| 怕黑 | 负面 | 黑暗、恐惧 | 夜间独处事件更容易触发 |
| 护短 | 正面 | 同伴、冲突 | 同伴受辱时更可能顶撞玩家 |
| 完美主义 | 负面 | 工作、执念 | 连续失败后疲劳增长更快 |
| 星象过敏 | 中性 | 星象、身体 | 星象台远征收益略高、疲劳也略高 |
| 记仇 | 负面 | 冲突、记忆 | 关系下降后更难恢复 |
| 收集癖 | 中性 | 物件、城市 | 更容易提出逛街与寻物意见 |
| 雨夜忧郁 | 负面 | 雨、孤独 | 雨夜对话更容易触发性情文本 |
| 话痨 | 正面 | 人群、表达 | 议事厅更常发言 |
| 沉默寡言 | 中性 | 独处、观察 | 意见更少，但情报更准 |

**是否带数值**：本版建议特性只做「叙事标签 + 事件权重」，不直接改四维。理由是避免与疤痕、等级、克隆叠加后难以解释；如果后续要黑暗地牢式数值癖好，可给每条特性加「轻量修正」字段，但需要单独平衡。

### 3.3 当前 buff / debuff

新增 `conditions`，与战斗内的 `ActiveEffect` 分开：

- 战斗内效果仍然只存在于 `BattleUnit`，战斗结束即消失。
- 基地级状态才进入 `conditions`，例如：
  - 诊所治疗后「恢复期」：疲劳恢复 +10%，持续 1 天。
  - 助手鼓励「被看见」：下次对话羁绊 +1，持续到当天结束。
  - 星象远征「星辉余韵」：下次调查洞察 +3，持续 2 小时。
  - 特性触发的「雨夜忧郁」：共情 -2，持续到雨停（按天数）。
- 每条状态含名称、类型、来源、描述、剩余分钟、是否可被诊所移除。
- 到期由 `advance` 统一清理；跨日时按真实时间扣减。
- 档案「状态概览」显示为 buff/debuff 标签，悬停或聚焦显示来源与剩余时间；没有状态时显示「此刻没有额外状态」，不占空卡。

### 3.4 档案改版

五页：状态概览 / 魔法能力 / 关系网络 / 倾向 / 心愿与羁绊。

- 标题下新增「当前目标」一行与「契约剩余 X 日」一行；目标可点开轨迹，契约可点开续签弹窗。
- 状态概览：血量、共情、疲劳、经验条、疤痕槽、当前 buff/debuff。
- 倾向页：目标详情、特性标签云、获取时间与来源；标签按倾向着色，不显示百分比。
- 心愿与羁绊：保留引语、疤痕、对话入口。
- 等级显示改为 `Lv.06 / 10`，满级显示 `MAX`；经验条显示「距离下一级还需 X」。

## 4. 会客厅与议事厅

### 4.1 每日意见

每天第一次跨日（或第一次进入会客厅）生成 2–4 条意见，作者从「在基地、未退役、未死亡」的角色中选，优先高羁绊、有相关特性、目标匹配的人。

意见结构：

| 字段 | 说明 |
| --- | --- |
| 作者 | 角色 id |
| 主题 | 经费、排班、设施、同伴、城市、私人心愿 |
| 正文 | 2–3 句，第一人称，带具体请求 |
| 请求 | 例如「拨 300 星砂给宿舍换灯」「让砂糖今晚别出勤」 |
| 选项 | 采纳 / 暂缓 / 驳回，各带小效果 |
| 助手点评 | 助手对这条意见的判断或吐槽，可能揭示隐藏代价 |
| 状态 | 待处理 / 已采纳 / 已暂缓 / 已驳回 / 已过期 |

默认效果控制在可解释范围：

- 采纳：支付少量资源或调整排班，获得羁绊、声望、特性或次日状态。
- 暂缓：不付资源，作者羁绊 -1，意见保留到次日。
- 驳回：不付资源，作者羁绊 -2；若涉及同伴，可能降低同伴关系。
- 同一天最多处理 3 条，未处理的次日过期并记一条日志。

### 4.2 助手

- 在会客厅或议事厅指定一名助手，可随时更换；助手必须留在基地。
- 助手在议事厅左侧显示全身剪影、名字、当前目标与一句立场。
- 每条意见生成时，助手给出一句建议：支持、反对、或指出隐藏风险。建议口吻由原型、特性、与作者的关系决定。
- 机制收益：助手点评有概率揭示该意见的隐藏效果（例如「采纳会让她更依赖你」）；每天第一次采纳助手建议，助手羁绊 +1。
- 助手外出执行委托时，议事厅显示「助手外出」，不提供点评，不阻断意见处理。

### 4.3 界面

会客厅房间详情中央显示当前发言者的全身剪影，右侧是意见卡；点击「进入议事厅」打开完整三栏。

```
┌ 议事厅 ───────────────────────────────────────────────┐
│ 左侧：助手全身剪影        中央：当前意见              右侧：今日意见队列 │
│ ┌──────────────┐   ┌──────────────────────────┐   ┌──────────────┐ │
│ │              │   │ 作者 · 主题 · 第 15 日    │   │ 01 经费      │ │
│ │   助手剪影    │   │ 「能不能把走廊的灯…」      │   │ 02 排班      │ │
│ │              │   │                          │   │ 03 私人心愿  │ │
│ │ 零青 · 助手   │   │ 采纳 / 暂缓 / 驳回        │   │              │ │
│ │ 「她其实在害怕」│   │ 助手：这不是灯的问题。     │   │ 已处理 1/3   │ │
│ └──────────────┘   └──────────────────────────┘   └──────────────┘ │
└──────────────────────────────────────────────────────────────────┘
```

- 全身剪影复用现有 SVG 立绘：CSS 去色、压暗、加轮廓光，不新增资产。
- 会客厅内嵌版本只显示「今日意见」与当前发言者剪影，不显示完整队列。
- 空状态：今日没有意见时显示「今晚大家都很安静」，并提供「去和她们聊聊」。

### 4.4 LLM 边界

意见生成本质是结构化内容生成：

- 输入：日期、房间等级、资源、每位角色的目标/特性/状态/关系、最近 5 条日志。
- 输出：意见 JSON（作者、主题、正文、请求、三个选项的固定效果 id），不接受自由数值。
- 本地校验：作者必须在场、主题必须枚举、正文长度 40–160 字、效果必须在预定义表内、资源扣除不得为负。
- 失败回退：使用种子模板生成，不阻塞每日流程。
- 当前版本只实现模板生成；LLM 适配层保持只读，意见文本不能直接改状态。

### 4.5 边界情况

- 没有可发言角色：不生成意见，记录「安静的一夜」。
- 全员外出：意见延后到有人回到基地的次日。
- 助手被派遣：保留任命，显示外出；归来后恢复点评。
- 意见作者死亡或退役：该条意见标记「已失效」，不扣羁绊。
- 意见队列上限 6 条；超出时最旧的自动过期。

## 5. 星象台远征

### 5.1 规则

星象台从「只加空间容量」改为真正的远征设施。

| 设施等级 | 队伍上限 | 每轮时长 | 每轮收益 | 每轮疲劳 | 每轮经验 |
| --- | --- | --- | --- | --- | --- |
| 1 | 1 人 | 90 分钟 | 120 星砂 | +6 | +4 |
| 2 | 2 人 | 75 分钟 | 180 星砂 | +7 | +5 |
| 3 | 2 人 | 60 分钟 | 240 星砂 | +8 | +6 |
| 4 | 3 人 | 60 分钟 | 300 星砂 | +9 | +7 |

- 收益按「队伍中最高洞察 + 平均共情」微调：每 10 点洞察 +1%，上限 +20%。
- 队伍中每有一名带「星象」标签的角色，收益 +5%，最多 +15%。
- 远征没有战斗与失败，只有疲劳与时间成本；疲劳达到 80 自动返回，并记录日志。
- 可随时召回，已完成的轮次照常结算，未完成轮次不结算。
- 同一角色不能同时远征与派遣；退役、治疗、休息中不可加入。
- 远征期间角色状态为 `expedition`，基地、名册、地图都显示为「星象远征中」。

### 5.2 结算

远征纳入 `advance` 的同一事件循环，而不是另开计时器：

- 每轮结束时刻作为事件插入现有队列，按真实时间结算，跨午夜按实际轮次归日。
- 一次推进 180 分钟可能跨 2–3 轮，逐轮发钱、加疲劳、加经验。
- 自动返回、手动召回都走同一个 `settleExpedition`，避免重复结算。
- 存档只存 `startedAt`、`cyclesDone` 与队伍，不存计时器。

### 5.3 界面

- 星象台房间详情：星图、当前远征卡、下一轮倒计时、预计收益、召回按钮。
- 「安排远征」弹窗：可选角色、显示每轮收益/疲劳/预计返回时间、容量与状态校验。
- 空状态：显示「星象台正在等待一个愿意抬头的人」，并提供安排入口。
- 远征卡显示「已运行 3 轮 · 累计 540 星砂」，避免玩家只看到倒计时。

### 5.4 经济位置

远征是低风险、低强度的稳定收入：一轮 120–300 星砂，低于战斗委托，但不需要玩家反复确认。它的真实成本是角色疲劳与机会成本（这段时间不能派遣），不是失败惩罚。

## 6. 诊所

诊所从通用房间弹窗改为专用界面，四个动作分区，危险操作二次确认。

### 6.1 动作表

| 动作 | 费用 | 时间 | 效果 | 限制 |
| --- | --- | --- | --- | --- |
| 治疗 | 240 星砂 | 90 分钟 | 血量回满，疲劳 -30，移除所有可移除 debuff | 血量未满或有 debuff |
| 静养 | 120 星砂 | 120 分钟 | 血量 +40%，疲劳 -60，移除 1 个 debuff | 疲劳大于 0 |
| 记忆清除 | 4,000 星砂 | 120 分钟 | 移除全部精神疤痕；等级与经验重置为 1 / 0；羁绊与全部同伴关系重置为 50 | 至少 1 条精神疤痕或等级大于 1 |
| 克隆 | 18,000 星砂 | 120 分钟 | 生成 1 级克隆体，继承全部技能，对玩家羁绊 85 | 有空余席位；原体存活；每个原体限 1 个克隆 |

### 6.2 记忆清除

这是「保留角色、重置换成长」的止损，不是无代价洗点。

- 移除全部 `kind === 'mental'` 的疤痕；肉体疤痕保留，其属性减损也保留。
- 等级回到 1，经验归零；四维按 `baseStats` 重算，再叠加保留的肉体疤痕。
- `bond` 与 `relationships` 全部设为 50（平常）。包括对玩家的关系。
- 该角色的对话历史清空，只保留一条系统日志「她的记忆被重新整理过」。
- 特性保留（人格倾向不因失忆消失），目标改为「空白」，之后可由事件重新生成。
- 立绘、技能、元素、外观不变。
- 确认弹窗必须逐条列出「会失去什么」，不能只写「重置」。

### 6.3 克隆

定位是后期快速补充战力，不是免费复制。

- 新角色 id 为 `clone-${原体 id}-${序号}`，名称显示为「月见桃 · 克隆」，代号 `CLONE-01`。
- 等级 1，经验 0；四维使用原体的 `baseStats`，不继承等级成长。
- 继承原体当前全部技能（含奥义），这是克隆的核心价值。
- 对玩家羁绊 85（爱意阈值），对其他人关系 50；没有疤痕，没有远征/派遣状态。
- 外观、元素、特性复制；目标改为「理解自己是谁」。
- 每个原体只能克隆一次；克隆体不能再克隆；死亡或退役角色不能作为原体。
- 需要 1 个空余契约席位；席位不足时按钮禁用并说明原因。
- 克隆体的合同只有 7 日，续签费按等效 5 级计算（2,340），不按实际 1 级计费；这是防止「低成本复制满技能角色」的维护成本。
- 克隆完成写入日志与纪念档案的「来源」字段，便于之后做身份剧情。

### 6.4 界面

```
┌ 月光诊所 ────────────────────────────────────────────┐
│ 左侧：当前角色剪影 / 床位状态                          │
│ 右侧：四个动作卡                                      │
│  治疗 240 · 90 分钟    静养 120 · 120 分钟            │
│  记忆清除 4,000 · 重置等级与关系（危险）               │
│  克隆 18,000 · 需要 1 个空席位（危险）                 │
│ 底部：当前血量/疲劳/疤痕/席位与星砂校验                 │
└──────────────────────────────────────────────────────┘
```

- 记忆清除与克隆各有一个确认层，列出代价、保留项、不可逆提示。
- 治疗/静养可直接执行；执行后角色进入 healing/resting，时间推进结算。
- 诊所界面同时显示「谁在候诊」，避免玩家在角色列表与诊所之间来回找。

### 6.5 边界情况

- 星砂不足：禁用按钮，显示缺口。
- 席位不足：克隆禁用，提供「去扩建宿舍」入口。
- 角色在任务/远征/治疗中：不可执行诊所动作。
- 记忆清除后等级下降导致血量上限下降：当前血量取新上限；若为 0，至少保留 1。
- 克隆 id 冲突：序号递增；存档校验拒绝重复 id。

## 7. 成长、雇佣期与一键派遣

### 7.1 等级上限 10

经验曲线按「推荐等级下的两次战斗或四次调查升一级」反推，不再使用固定经验值。

| 当前等级 | 升级所需 | 推荐等级战斗胜利 | 推荐等级调查成功 | 战斗次数 | 调查次数 |
| --- | --- | --- | --- | --- | --- |
| 1 → 2 | 60 | 30 | 15 | 2 | 4 |
| 4 → 5 | 120 | 60 | 30 | 2 | 4 |
| 7 → 8 | 180 | 90 | 45 | 2 | 4 |
| 9 → 10 | 220 | 110 | 55 | 2 | 4 |

- 升级需求：`R(L) = 60 + 20 × (L − 1)`；战斗经验 `B(L) = 30 + 10 × (L − 1)`；调查经验 `I(L) = 15 + 5 × (L − 1)`。始终满足 `R = 2B = 4I`。
- 经验由**委托的推荐等级**决定，不由角色当前等级决定。高等级角色打低推荐委托会明显变慢，低等级角色打高推荐委托能获得更多经验，但生存与契合度风险更高。
- 完整成功：战斗胜利、调查成功，获得全额经验。
- 部分结果：击退获得 60% 战斗经验，平局 40%，失败 25%；调查受阻 30%。这些结果不能替代「两次胜利」，只作为失败后的保底。
- 每场结算最多提升 1 级，多余经验保留到下一级，避免一次高难委托连跳两级。
- 累计到 10 级仍需 1,260 经验，节奏与旧方案一致，但每一级的来源被拆成可预期的两次战斗或四次调查。
- 升级时：最大生命 +4，最大共情 +2，按原型成长两项四维（主属性 +2，副属性 +1）。
- 升级不重置疲劳，不回血；只提高上限。
- 满级后经验不再增长，显示 `MAX`。
- 记忆清除、克隆都从 1 级重新开始；等级不能超过 10。
- 远征每轮经验固定 5–8，远低于同推荐等级的调查，只作为长线补充，不能替代委托升级。
- 实现位置：`src/combat.ts` 的 `rewards.exp` 改为按 `mission.recommendedLevel` 计算；`src/game.ts` 中调查的固定 `+8` 改为 `I(mission.recommendedLevel)`；升级逻辑统一放进 `src/progression.ts`，战斗与调查只负责发放经验。

**示例**：Lv.4 的零青升 Lv.5 需要 120 经验。她完成两次推荐等级 4 的战斗（每次 60）刚好升级；或完成四次推荐等级 4 的调查（每次 30）刚好升级。若她越级打推荐等级 7 的战斗，单次 90 经验，但仍受「每场最多升 1 级」限制。

**设计意图**：让升级速度与「打对了难度的委托」绑定，而不是刷最低级战斗。两次同推荐等级的战斗刚好升一级，玩家可以精确规划一晚的排班。

### 7.2 推荐等级

由委托难度、敌人档位、目标属性共同决定，写入 `Mission.recommendedLevel`：

| 委托 | 敌人 | 推荐等级 |
| --- | --- | --- |
| 糖果街的失眠电波（调查 45 分钟） | 无 | 2 |
| 末班车上的第十三人（战斗 60 分钟） | 游荡 + 灾厄 | 4 |
| 镜中的另一轮月亮（战斗 90 分钟） | 灾厄 | 6 |
| 寻找走失的星尾猫（调查 30 分钟） | 无 | 1 |
| 旧钟楼的未寄信（调查 60 分钟） | 无 | 3 |
| 糖果王座（战斗 90 分钟） | 王座 + 碎屑 | 7 |
| 空月之下（战斗 90 分钟） | 王座 | 9 |

界面显示「推荐 Lv.6」与「队伍平均 Lv.5」，低于推荐 2 级以上时给出警告，但不禁止派遣。

### 7.3 一键编队

在委托详情里提供「一键编队」：

1. 过滤：在职、未退役、未死亡、待命、血量 ≥ 30、疲劳 < 80。
2. 评分：`0.45 × 主属性 + 0.2 × 等级 + 0.15 × 共情 + 0.1 × 当前血量比例 + 0.1 × 特性匹配 - 疲劳惩罚`。
3. 按评分降序取到队伍上限；战斗优先覆盖不同原型，调查优先高主属性。
4. 自动填入编队槽，显示「推荐队伍已就位」与预计契合度；玩家再按「确认派遣」。
5. 没有可用角色时，按钮禁用并说明原因（全员忙碌/血量过低/疲劳过高）。

**关于「一键派遣」**：默认做成「一键编队 + 确认」，避免误派不可撤回。若你希望真正一次点击就出发，可加设置项「快速派遣」，开启后按钮直接调用 `dispatch`，并在提示条提供 10 秒撤回入口。撤回需要新增行动，属于额外范围。

### 7.5 雇佣期、续签与退休区

每名在职角色都有一份到期合同。合同不是每日工资，而是一次性续签费；它把「高等级角色很强」与「高等级角色很贵」绑定在一起。

**合同长度**

- 新雇角色默认 10 日；克隆体 7 日。
- 初始四人的到期日错开，避免同一天全部到期：月见桃第 20 日、砂糖第 23 日、零青第 26 日、雾眠第 29 日。
- 续签从**当前到期日**往后延长，不是从今天重新计算；提前续签不会损失天数。

**续签费用**

`续签费 = round(250 + 220 × 等级^1.45)`

| 等级 | 续签费 | 说明 |
| --- | --- | --- |
| 1 | 470 | 低等级培养成本低 |
| 3 | 1,328 | 前期主力 |
| 5 | 2,340 | 中期主力 |
| 7 | 3,858 | 高等级开始形成压力 |
| 10 | 6,300 | 满级角色需要稳定收入支撑 |

- 费用随等级超线性增长：10 级约为 1 级的 13 倍，但战斗力远不到 13 倍，迫使玩家在「保留满级主力」与「轮换低等级新人」之间做选择。
- 克隆体按**等效 5 级**计费（2,340），不按实际 1 级计费，避免「克隆满技能角色只付 1 级合同」的漏洞。
- 记忆清除会把等级降回 1，续签费也随之下降；这是止损的隐性收益，但代价是战力与关系归零。

**到期与退休区**

- 到期日当天仍可出勤；次日凌晨第一次推进时结算。
- 若到期时正在委托、远征、治疗或休息，给一次「归队宽限」：合同在回到待命状态的那一刻到期，不打断进行中的行动。
- 到期后：`status = retired`、`retiredReason = 'contract'`、释放契约席位、清空编队、羁绊 −6，写入日志与通知；不进入纪念墙，因为人还在。
- 容量口径同步改为「在职人数」：`!retired && !dead`。当前雇佣校验只排除了死亡，退役仍占席位，实现时要一并改掉；伤退也释放席位，旧日志「席位仍留在基地」改为「席位已空出」。
- 退休区放在市场页底部，同时收录「合同到期」与「伤退」两种；死亡角色只在纪念墙，不在这里。
- 返聘费用为续签费的 1.25 倍，合同 10 日，从返聘当天起算；需要 1 个空余席位。
- 返聘后回到待命、默认在会客厅，等级、技能、特性、疤痕、关系全部保留；羁绊不会因返聘恢复。
- 伤退角色可以返聘，但界面要提示「她仍有 4 道疤痕」；合同到期角色返聘没有额外惩罚。
- 克隆体到期后同样进入退休区，返聘费按等效 5 级计算。

**界面**

- 名册卡：合同剩余天数 chip；≤3 日变琥珀色，≤1 日变粉色并带「即将到期」。
- 档案标题下：`契约剩余 6 日 · 第 20 日到期`，旁边是「续签」按钮。
- 续签弹窗：当前等级、费用、新到期日、续签后每日均摊成本；星砂不足时显示缺口。
- 市场页退休区：卡片显示姓名、等级、退役原因、返聘费、疤痕数；按钮「返聘」。
- 到期前 3 日与 1 日各发一次站内通知；到期当天在通知中心保留一条可跳转到退休区的记录。

**边界情况**

- 星砂不足：续签/返聘按钮禁用，显示缺口，不扣款。
- 席位不足：返聘禁用，提供「去扩建宿舍」。
- 角色在委托/远征中：不能续签，也不能返聘；先归队。
- 同一天多名角色到期：逐人结算，通知合并为一条「3 份合同已到期」。
- 退休区容量不设上限；已死亡角色不占退休区。
- 合同到期不触发死亡、不生成疤痕、不改变同伴关系。

### 7.6 退休金与远程联络

退休不是一次性结算，而是一笔持续支出。它让「保留一批高等级退役角色」也有代价，避免后期星砂只进不出。

**退休金**

`每日退休金 = round(40 + 20 × 等级^1.55)`

| 等级 | 每日退休金 | 说明 |
| --- | --- | --- |
| 1 | 60 | 刚退役的新人 |
| 3 | 156 | 前期主力 |
| 5 | 280 | 中期主力 |
| 7 | 444 | 高等级退役 |
| 10 | 750 | 满级退役，长期负担 |

- 对象：所有 `retired && !dead` 的角色，合同到期与伤退都算；死亡当天停发，进入纪念墙。
- 结算：每天 00:00 在现有 `advance` 事件循环里扣款；跨多天推进时逐日结算，不能漏天或重复。
- 欠付：星砂不足时先扣到 0，剩余计入 `pensionDebt`，并记「欠付退休金」日志；当天城市声望 −2，相关角色 `pensionMissed += 1`。次日优先补欠款，再扣当天退休金。
- 补清欠款后 `pensionMissed` 归零；欠付期间退休区的卡片显示「欠付 2 日」，远程对话的开场白会提到这件事，但不阻止聊天。
- 返聘或死亡立即停止后续退休金；已经产生的欠款不会消失。
- 退休金进入当日经营支出样本，记录页能看到这笔固定开销。

**远程联络**

- 退休区每张卡片增加「联络」按钮，打开手机消息风格的对话，而不是把角色拉回基地。
- 对话沿用现有消息记录与本地剧情回复，增加远程标识：`远程联络 · 信号 2 格`、`她住在城市另一端`、送达/已读状态。
- 远程聊天每天前 2 次、每次羁绊 +1；不再提供派遣、治疗、休息等基地操作。
- 退休角色不能出勤，但可以聊天、被返聘；死亡角色只能看纪念墙，不能联络。
- 欠付退休金时，她的第一句会变冷淡；补清后恢复正常语气。这是叙事反馈，不额外扣数值。

### 11.1 状态回归

- 合同：初始到期日错开、到期次日退役、忙碌时归队宽限、续签从原到期日顺延、续签费随等级增长、克隆按等效 5 级计费、返聘 1.25 倍并需要席位、死亡角色不进入退休区。

- 远程联络：退役角色可聊、每天前 2 次 +1 羁绊、欠付时冷淡开场、死亡角色不可聊、不会改变出勤状态。
- 特性：每次派遣 1–2 条、上限 8、不重复、同种子可复现、克隆继承。
- 状态：buff 到期清理、跨日扣减、诊所移除 debuff、不可移除状态保留。
- 意见：每日只生成一次、作者必须在场、决定只结算一次、过期不扣资源、助手外出不点评。
- 远征：跨午夜多轮结算、召回只结已完成轮次、疲劳 80 自动返回、不能重复结算、合同到期时中止并归队。
- 诊所：治疗/静养条件、记忆清除移除精神疤痕并重置、克隆继承技能与爱意羁绊、容量与费用校验。
- 迁移：v3 存档补齐默认值（含合同到期日）；坏特性/坏意见/坏远征被拒绝。
- 一键编队：过滤忙碌与低血、人数上限、评分排序稳定、无可用角色时返回空。
