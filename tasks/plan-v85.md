# v85 七项调整

> 编号按你给的顺序；第 5 项你写了两遍（小队上限 + 奖励倍率），这里合并成 5a/5b。

## 1. 市场升级费用 −50%

- 位置：`src/economy.ts` → `marketUpgradeCost(level)`，现在是 `[0, 6000, 12000, 24000]`。
- 改法：乘 0.5 → `[0, 3000, 6000, 12000]`；同时把它挪进 `balance.ts` 的「市场」分组（现在是硬编码表），
  以后调价不用改代码。
- 影响面：`applyUpgradeMarket` 只读这个函数，UI 的报价也读它，改一处即可。

## 2. 城市安定度（reputation）加一个消耗口：向势力借星砂

现状：安定度只涨不跌（委托 +2、Boss +8、事件 ±），除了高级招募扣一点，没有真正的「花安定的地方」。

设计（新动作 `borrowFromFaction`）：

```
借 1 点安定 → 换 **300 星砂**，单次 1–10 点
前置：该势力态度 ≥ 中立（standing ≥ 30）
代价：该势力好感 **−2**（借的是他们的钱）、当天该势力不能再借
上限：每天合计最多借 **10 点**安定（防止一路借空）
```

- 入口：会客厅「势力代表」页每张卡多一个「借星砂」按钮（与代表委托并列），或势力档案页的「财务往来」区块。
- 平衡理由：安定度现在是纯正向资源，借星砂把它变成「应急现金」，但代价是好感与议价能力（`advancedCost` 也吃安定度）。
- 数值进 `balance.ts`：`factionLoanPerPoint 500`、`factionLoanDailyCap 20`、`factionLoanStandingCost 1`。
- 结算：立刻加钱、扣安定、扣好感；写一条 `finance` 日志；不能借到安定 < 0。

## 3. 魔女化锁定 + 首次弹窗

现状：`setWitchForm({outfit: undefined})` 免费退出魔女形态；侵蚀到第 3 阶段会自动 `witch = true`。

改成：

- **锁定**：`setWitchForm` 不带 outfit 时直接拒绝，提示「需要注射月蚀抑制剂才能解除」。
- **解除途径**：新增动作 `injectSuppressant { girlId }`，消耗 1 支 `moon-drug`（月蚀抑制剂）：
  `witch = false`、`drugUntilDay = day + 10`、加一条日志与提示。仓库没有药时按钮置灰并说明去哪买。
- **首次弹窗**：新增 `state.witchAlerts: string[]`（已提示过的少女 id）。第一次 `girl.witch` 变 true 时
  推一条 `notice`（复用现有 notice 系统，kind: 'care'），标题「她的影子长出了角」，正文写清
  「已锁定魔女形态，需要月蚀抑制剂才能解除」；同一位少女只提示一次。
- 连带：档案页第五格按钮文案改成「注射抑制剂（解除锁定）」，没药时显示「仓库缺药」。

## 4. 月蚀庭的首领与成员默认魔女形态

- 位置：`src/content/factionLeaders.ts`、`src/content/factionGirls.ts`（witch 阵营的人）+ `factions.ts` 的 `subjectOfLeader/OfGirl`。
- 改法：witch 阵营的静态角色加 `witch: true` 与 `outfitId: 'witchform'`，并补 `witchForm`（用她们的配色生成，
  `witchOutfitFor()` 已有现成实现）。
- 表现：编成池、势力档案、战斗里她们直接是魔女形态；普通服装锁定（与第 3 条一致）。
- 边界：这属于静态内容，只影响新开局与新导入；老存档里已经进名册的她们不会被强制改写（避免动玩家数据）。

## 5a. 战斗委托的小队上限改成跟魔物数量走

现状：`roster.ts` 的 `squadLimit(mission)` 战斗 = `balance.squadLimit`（3），调查 = ≤2。

**已定**：`上限 = max(3, 魔物总数)` —— 魔物 ≤ 3 只时恒定 3 人；超过 3 只时按魔物数量放开
（4 只 → 4 人，5 只 → 5 人）。上限同时受在册人数与队伍编成界面约束，
UI 里写死的「最多 3 人」提示改成按这次委托算出来的数字。

## 5b. 战斗委托奖励与魔物数量挂钩

- 位置：`simulateBattle` 的 `rewards` 计算（`src/combat.ts`），或 `settleCombat` 里按 `mission.enemyIds.length` 放大。
- 改法：`reward × (1 + 0.15 × (魔物总数 − 1))`，系数进 balance（`rewardPerExtraMonster 15`）。
- 与现有「辖区奖励%、势力加成」相乘，不额外叠加乘算顺序问题：先算基础 → 乘辖区/势力 → 再加怪物系数。
- UI：委托卡上把「报酬」拆成 `基础 × 怪物系数 × 辖区` 的说明，避免又出现「数值对不上」。

## 6. 污染对魔物的增幅再提高

现状：`pollutionEffect(level)` → `enemyHpPct = level×0.32`、`enemyPowerPct = level×0.18`、`targetPct = level×0.10`。

改法（同时把系数搬进 `balance.ts`）：

```
enemyHpPct     level × 0.55   （100 污染 → +55% 血量，原来 +32%）
enemyPowerPct  level × 0.38   （100 污染 → +38% 伤害，原来 +18%）
targetPct      level × 0.16   （判定难度也跟着涨，原来 +10%）
rewardPct      level × 0.22   （难度涨了报酬也涨，原来 +16%）
```

- 影响：高污染区委托明显变硬，但报酬同步上去；`pollutionForecast` 的文案会跟着显示新数值。
- **已定**：直接按 0.55 / 0.38 上，不再给过渡值；如果一局下来明显打不动，再单独调这两项。

## 十、追加调整（2026-11-05 追加，并入 v85）

### 10.1 小队上限（替代原 5a）

- `squadLimit(mission)`：战斗委托 `= Math.max(3, mission.enemyIds.length)`；调查仍 ≤2 不变。
- 5 只魔物 = 5 人，但宿舍在册人数与编成界面才是真正约束，超出时按在册人数来。
- 编成界面与委托详情里的「最多 3 人」文案改成读这个函数的结果。

### 10.2 高级招聘：费用减半 + 候选人必须来自卡库

- 费用：`advancedCost(level)` 的星砂部分 **×0.5**（`1200 × level` → `600 × level`），
  安定度消耗保留（这是安定度的正经消耗口之一）。数值搬进 `balance.ts`。
- 候选人来源：不再用 `makeCandidate()` 现场合成，改成**从契约卡库取**：
  1. 前端点「高级招聘 N 级」→ `scanLibrary()` → 在卡库里挑一张（优先等级接近 N、小卡优先、排除已用过的 hash）；
  2. 把这张卡的等级/四维归一到 N 级（沿用 v83 的 `normalizeOpeningLevel` 思路，改成按目标等级缩放）；
  3. 新增动作参数 `advancedRecruit { level, card? }`：带卡就按卡入册，不带卡保留旧的合成逻辑（卡库不可用时兜底）。
- 文案：卡库来源要标出来（「协会渠道 · 卡库」 vs 「协会渠道 · 临时登记」），避免又出现「卡库里的卡怎么没进来」。

### 10.3 议案要出现「给钱」的类型

现状：模型写出来的议案几乎都在扣星砂（`shouldWarnAllSpend` 已经在提示，但只是提示）。

改法：

1. **提示词**：契约里加一条**建议**（不是硬规则）——`opinions` 的题材尽量错开（钱、人、势力、辖区各一条），
   其中优先留一条「给事务所星砂、代价压在疲劳/羁绊/侵蚀」的议案；
   **同一天出现同类议案是允许的**，模型照实写就行，不要为了凑类型硬造。
2. **校验**：`validateNightProposal` 里新增软警告（不判死）：全部议案都扣星砂时，把
   「至少补一条给星砂、代价压在角色身上的议案」写进 `warnings`，界面照常显示，玩家可以选择重新生成。
3. **本地兜底**：首夜与「生成失败回退」用的本地议题池加两条收入型模板
   （「协会追加拨款」扣疲劳、「月蚀庭预付订金」扣势力态度），保证一晚上不会一水儿都是花钱。
4. **结算**：`changes` 已经支持 fatigue / bond / corruption / faction，逻辑不用动，只补文案与枚举校验。

### 10.4 势力任务新增「索款」形态

势力会直接向你要钱：**索要 200–1000 星砂，每 200 点换 1 点好感**（不满 200 的部分不给好感，也不退还）。

- 新形态 EnvoyKind = tribute（与 coop / raid / loan 并列，权重进 balance.ts，默认 20）：
  - 金额按种子在 200 / 400 / 600 / 800 / 1000 里取，也允许玩家加钱到下一档；
  - 支付：立刻扣星砂、好感 +（金额 / 200 向下取整）；
  - 不接：当天该势力什么都拿不到，好感不变（不惩罚，只是错过）；
  - 与借星砂互为镜像：借星砂是「拿安定换钱、掉好感」，索款是「拿钱换好感」。
- 数值：envoyTributeMin 200、envoyTributeMax 1000、envoyTributePerStanding 200、envoyTributeWeight 20。
- 界面：卡片上直接给三档金额按钮（小额 / 标准 / 足额），点了即结算，不需要再进地图。
