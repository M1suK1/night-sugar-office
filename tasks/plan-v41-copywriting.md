# v41 方案：全游戏文案重塑与叙事润色（分阶段执行）

> **目标**：彻底根除当前大量“机械短句”、“标签式断句”和“说明书翻译腔”，建立具有连贯语流、空间触感与冷调都市怪谈文学质感的沉浸式文案体系。  
> **硬性边界**：**不改动任何业务逻辑代码**，只替换展示型文本属性；所有 ID、数值、效果参数、类型接口保持 100% 绝对一致。

---

## 1. 现状痛点诊断：为什么现在的文案“读起来很难受”？

检查当前代码库中的文案（`missions`、`monsters`、`skills`、`items`、`worldbook`、`labels`），存在三大普遍病态：

### 症状一：机械短句碎拼（缺乏语流与自然呼吸）
* **现状典型**：
  * *“一只由回声拼成的猫。它叫你的名字时，声音比你更像你。不要答应。”*（`monsters.ts`）
  * *“一节没有编号的电车，在午夜后多停了一站。车窗里坐满了没有脸的人，他们都在等一个不会来的名字。”*（`monsters.ts`）
  * *“一截缠着干枯荆棘的木杖。它扎手，但扎得比魔物狠。”*（`tier1.ts`）
* **问题剖析**：几乎所有句子都被强行切断在 8~14 个字以内，通篇都是“一个XX。它很XX。千万不要XX。”的公式化碎句堆砌，缺乏复句承转、主次起伏和阅读节奏，显得刻板、贫瘠且充满 AI 模板感。

### 症状二：说明书式干瘪叙述（缺乏场景深度与生活质感）
* **现状典型**：
  * *“血量上限由体质与等级决定，当前血量低于上限时行动会变慢。血量低于 25 的契约者不能派遣；战斗中倒下会留下疤痕，第五道疤痕意味着退役或死亡。”*（`worldbook.ts: wound`）
  * *“学校食堂的蒸汽连续几晚不肯散去，白雾里能听见有人在数盘子。值班的阿姨说，数到七十就会停下。”*（`missions-extra.ts`）
  * *“普通治疗按 30 分钟一档计价，治疗期间无法派遣，也不会恢复疲劳。疲劳请回宿舍休息。”*（`ClinicPanel.tsx`）
* **问题剖析**：把游戏机制直接翻译成冷冰冰的功能说明条目，或者仅用一两句话草率勾勒一个场景，缺失了作为“深夜事务所”所面对的具体市民口供、街道细节、异象触感和人情冷暖。

### 症状三：标签化与概念空洞（缺乏器物细节与身体感知）
* **现状典型**：
  * *“一瓶黑得发亮的糖浆。咽下去像吞了一口铁锈。恢复 30 点生命。”*（`tier1.ts`）
  * *“把‘今晚可以睡个好觉’包进糖纸里。吃下去的人会想起柔软的枕头。”*（`skills.ts`）
* **问题剖析**：过多使用“柔软的枕头”、“不会来的名字”这种悬浮的象征修辞，缺少实际器物的打磨痕迹、重量、气味以及施法时肌肉的酸痛和魔力在骨骼里流动的实体触感。

## 2. 润色方针与叙事准则

1. **建立完整语流**：摒弃病态碎句，改用结构完整、音律协调的复句与长短句结合，使段落具备舒缓或紧绷的节奏呼吸感。
2. **具象化感官描写**：调动温度（夜雨的潮湿、金属的冷硬）、声音（电车电极打火声、老木地板呻吟）、光影（霓虹被雨雾化开、星光在水洼的倒影）和气味（锈铁味、焦糖甜气、浸水纸张），赋予文本强烈的实体感。
3. **机制自然融入叙事**：在解释规则时，采用所长日记、值夜准则或事务所工作备忘录的语气，让数值逻辑自然依附于世界观事实，而非生硬宣读代码规则。
4. **语言风格统一**：保持深夜都市冷调、克制而富有深度的中文散文质感，既不轻浮网络化，也不故作高深谜语人。

## 3. 逻辑零破坏保障清单（开发安全底线）

为确保**绝对不动业务逻辑代码**，确立以下规则：

| 范畴 | 严格禁止改动的项（代码逻辑硬依赖） | 允许且专注改动的项（纯文案） |
| :--- | :--- | :--- |
| **任务（Missions）** | `id`, `x`, `y`, `difficulty`, `duration`, `reward`, `requirement`, `target`, `color`, `status`, `squad`, `work`, `enemyIds`, `enemyCount`, `rounds`, `district`, `window` | `title`（保持原主题微调或保留）, `category`, `description`（全方位扩充至 80~150 字） |
| **魔物（Monsters）** | `id`, `rank`, `element`, `color`, `maxHp`, `maxSpirit`, `stats`, `skillIds`, `spec`, `rules` | `epithet`（扩充更有韵味的称号）, `description`（外形生态细节充实）, `codex.habit`, `codex.weakness`, `trait`（润色为自然语言叙述，数值完全不变） |
| **技能（Skills）** | `id`, `school`, `resource`, `power`, `targets`, `side`, `cooldown`, `tier`, `accuracy`, `effects`, `selfCost`, `selfEffects` | `description`（重塑施法动作、代价与现象描摹） |
| **装备（Items）** | `id`, `faction`, `slot`, `tier`, `price`, `standingReq`, `stats`, `effect`, `amount`, `passive` | `description`（扩写器物来历、磨损质感、使用感受，附带数值说明文字保持原意） |
| **世界书（Worldbook）**| `id`, `enabled`, `constant`, `priority`, `order`, 词条总数（17 条保持不变） | `keys`（仅补充相关同义词，不删已有词）, `content`（全面升级为深度设定文本） |
| **UI 标签与提示** | 枚举键名、返回字段签名、状态标签名（`待命`, `派遣中` 等基础词保持不变） | `stageHints`（好感度阶段细腻独白）、各面板辅助说明提示段落 |

   ```powershell
   node .\node_modules\typescript\bin\tsc --noEmit
   ```
   确保 0 TS 错误，无遗漏闭合括号或引号。
2. **全量状态回归测试（逐文件运行）**：
   ```powershell
   # 19 个测试文件全绿，404 项用例必须 100% 通过
   npm test
   ```
3. **架构与依赖护栏检测**：
   ```powershell
   npm run check:rules
   ```
   确保无循环依赖，无 UTF-8 BOM，各文件体积合规。
