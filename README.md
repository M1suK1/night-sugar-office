# 夜糖事务所

黑色、雾白与蔷薇粉的魔法少女经营游戏前端原型。以原创等距夜城地图为核心，包含剪影立绘、战斗与调查两类派遣、自动战斗回放、七阶关系、疤痕与退役、契约经济、市场四标签、自定义契约者、装备与势力物资、侵蚀/魔女化、城市安定度与周期 Boss。

本版立绘统一使用分层剪影占位，仅用于验证服装、表情、导入 PNG 与头像联动等功能；完整分层美术将在后续替换，不影响现有数据结构与交互。

**仅前端。没有后端、模型请求、账号、支付或云端存储。** 剧情由本地关键词/脚本响应演示，界面有明确标识。

## 运行

建议 Node.js 22.18+ 或 24+，使用 npm。

```sh
npm ci
npm run dev -- --port 5173 --strictPort
```

打开终端打印的本地地址。生产预览：

```sh
npm run build
npm run preview -- --port 5173 --strictPort
```

浏览器不能通过双击 HTML 正确运行 Vite 的模块和绝对路径资产；请使用开发/静态预览服务。部署到域名根路径即可，不需要业务服务端。

## 可体验的内容

- **城市派遣**：地图/列表切换、战斗与调查分类筛选、缩放；悬停角色显示简报；拖动角色到任务点，或点击任务后编队；战斗最多 3 人、调查最多 2 人。低血量、疲劳、忙碌及重复派遣均有约束和内部提示。
- **自动战斗**：每 15 分钟一轮，洞察值随机波动决定行动顺序，技能按权重释放并判定命中；全自动、玩家不可干预。战斗以全屏剧场回放，支持播放、暂停、倍速、跳过与完整战报。胜利移除事件；时间耗尽为暂时击退，获得八成收益，魔物带伤回到池中；失败保留事件并留下疤痕。
- **人物档案**：状态、能力、关系、契约成长、外观装备、心愿六页；血量、共情值、疲劳、侵蚀度、五格疤痕、三技能与七阶关系。契约成长页显示当前目标、随机显露的特性、经验与升级进度、契约期限、退休金和欠缴。外观页提供三套衣柜预览、六种表情、装备栏与右侧仓库抽屉；装备可从仓库拖入法器/护符槽，侵蚀度在状态概览疲劳值下方。
- **侵蚀与魔女化**：战斗、Boss 与高疲劳会积累侵蚀；三阶段分别降低共情、提高其余属性。第三阶段成为魔女，需要每 10 日使用一次月蚀抑制剂；断药期最长 10 日，期间禁止派遣与远行，第 10 日死亡。
- **市场四标签**：候选名册、在册契约、势力物资、退休区。市场等级决定每日候选人数，可花星砂升级；高级招募可指定 1–6 级，但会消耗城市安定度。势力物资每天为每个势力刷新三个货位，可重复出现同一物品，但每个货位只能购买一次；售罄状态与次日刷新都记录在存档中。
- **自定义契约者**：五步登记向导，自由分配 260 点能力、选择三技能与三特性、挑选代表色、导入并裁剪 PNG 立绘；导入立绘后可由故事引擎读取画面补全身世与外貌，职阶会决定 260 点的自动分配；固定 1 级，登记后进入候选名册。
- **契约卡导出**：人物档案可把当前角色导出为本地 JSON 卡片，包含立绘、三技能、特性、关系、疤痕、装备与契约数据。市场「导入卡片」可在新存档重新登记，保留原始数值但不继承退役状态；卡片指纹避免重复导入，数据不完整时拒绝。
- **基地二级菜单**：点击会客厅、诊所、宿舍、星象台打开房间详情，不跳页。会客厅包含议事、成员、物资、势力代表四页；诊所与宿舍提供快捷照护；星象台可派两人远行。
- **契约经济**：雇佣有期限，到期需续签；退休金按等级每日计提，退役成员会持续占用事务所预算。欠缴过久会强制退役。月光诊所提供快速治疗、深度疗养、记忆重塑与复制契约，价格与限制写在按钮上。
- **会客厅与星象台**：基地会客厅可以批准、暂缓或驳回成员议题，也可任命值班助理；星象台可派两人远行，按小时结算，疲劳过高会自动返程。
- **退休区**：退役成员进入市场页的退休区，可返聘、查看退休金状态，并通过手机远程联络；每次通话消耗星砂，每日首次提升羁绊。
- **代价与纪念**：疤痕降低血量上限并附带精神或肉体后遗症；第五道疤痕导致死亡，角色移入星光纪念墙。累计四道疤痕可申请退役转任文职。
- **灯下私语**：自由输入、快捷话题、角色立绘、聊天历史、羁绊和场景记忆面板。配置叙事者后，模型会结合角色完整设定、关系网络、战斗经历与全部对话历史生成台词；失败时回退本地剧情。每条输入最多 500 字，每位角色保留最近 60 条消息，日羁绊增长有限制。
- **基地**：会客厅、月光诊所、晚安宿舍、星象台平面图；显示在场成员与位置；房间详情、交谈和扩建。扩建宿舍增加契约席位，其他设施扩建提升空间容量。
- **市场**：候选契约者筛选、搜索、完整档案及签约确认；资金和基地容量联动。退役成员保留在退休区，可远程联络或返聘。
- **城市危机**：第 16 日首次出现周期 Boss；Boss 在场时每 3 小时降低 1 点城市安定度，48 小时未处理额外扣 6 点。安定度影响雇佣折扣、每日委托数量与编队契合。
- **记录**：收入、支出、声望折线图；时间范围、键盘可访问的数据点、日志分类、战斗档案与分页。跨午夜结算按行动的实际完成时刻归日。\n- **编年史缓存**：生成或登记的魔物、少女、委托、议程与势力代表会写入独立编年史；即使内容从池中移除或委托完成，仍可在记录页按类别回看。缓存上限 200 条，随存档保存。
- **魔物图鉴**：六种魔物的几何剪影、属性、技能、习性与弱点；可从侧栏或战斗编队直接打开。
- **辅助功能**：内部通知、设置、操作手册、减少动画、存档导出、双重确认重置；每 12 秒自动推进 5 分钟或手动推进 30 分钟。

## 存档与演示边界

数据仅保存于当前浏览器、当前站点的 localStorage（`night-sugar-office:v1`）。刷新可恢复，清除站点数据会丢失；隐私模式/存储不可写时可继续游玩，但无法保证刷新后恢复。导出为 JSON 备份，**本版没有导入界面**。损坏或关系不一致的本地存档自动回退到初始演示状态。

初始数据为第 14 日夜班，内置 7 项委托（4 项战斗、3 项调查）、4 位在职角色、1 位退役角色、1 位候选角色、4 个房间和一条会客厅议题。委托是一次性演示内容，胜利后不再刷新；暂时击退或失败会回到事件池，并保留疤痕与疲劳。可在设置中重置体验。

战斗是确定性规则引擎：同一存档、同一编队、同一时间得到同一结果，模型无法改写战斗数值。每轮行动日志会展开命中与伤害的中间值，战斗结束后可回看完整剧场与战报。

## 代码结构与未来 LLM 扩展

- `src/game.ts` / `src/types.ts`：纯函数行动规则、状态模型、数据与恢复校验。
- `src/contracts.ts`：契约期限、退休金、欠缴、续签与返聘。
- `src/economy.ts`：市场等级、每日候选、高级招募、势力声望与物资价格。
- `src/items.ts`：装备、消耗品、月蚀抑制剂与装备技能。
- `src/factions.ts`：三大势力、货架、会客厅代表与每日任务。
- `src/progression.ts`：经验曲线、特性抽取、当前目标、侵蚀、值班助理与议题生成。
- `src/combat.ts`：确定性战斗引擎、命中与效果结算、疤痕与战后收益。
- `src/content/`：技能池、魔物模板、特性目录与种子内容包；未来可由生成式内容包替换。
- `src/llm.ts`：故事引擎连接、可编辑提示词、提案校验与本地数值分配；内容池已满时拒绝生成。
- `src/App.tsx`：页面导航、弹窗编排、持久化、时间、自动补充与通知。
- `src/components/`：派遣沙盘、编队、战斗剧场、档案、图鉴、纪念墙、剪影立绘、自定义向导、对话与辅助弹窗。
- `src/views/`：基地、市场、经营记录与市场四标签。
- `public/art/`：本地原创 SVG 城市；`public/fonts/`：本地子集字体。角色立绘当前由 `GirlPortrait` 渲染剪影，导入 PNG 则显示原图。
- `tests/`：38 项状态回归与 23 组真实浏览器交互验收。

## 故事引擎（可选）

设置 → 故事引擎可连接任意 OpenAI 兼容接口，并在浏览器内填写接口地址、模型与密钥。密钥、提示词与自动补充偏好只存于 localStorage，不写入游戏存档；刷新后保留，清除站点数据即删除。

- 「世界观与语气」「本次生成要求」可直接编辑，也可恢复默认。
- 每次连接测试、提案生成与角色起草都会写入「叙事引擎日志」：显示成功/失败、HTTP 状态、耗时、模型与服务端错误原文，可一键复制或清空；API 密钥不会写入日志。
- 「生成今晚的提案」在本地校验后落地 1 只魔物、1 位候选者、1 条战斗委托、1 条代表委托与 1 份会客厅议题；属性、轮次与奖励由本地规则计算。
- 生成的代表委托会直接挂到对应势力的会客厅代表名下；议题进入待议列表，可批准、暂缓或驳回。
- 自定义契约者在五步向导前提供「只导入立绘」入口：立绘会作为 `image_url` 发送给支持视觉的模型，用于补全身份、外貌与描述；每个字段标注「由使魔补全」并可单独重写，底部可重新生成全部。元素与职阶决定 260 点的自动分配，仍可手动调整；未点「登记并加入名册」前不会写入候选池。不支持视觉的模型会返回明确的接口错误，日志中保留状态码与服务端原文。
- 开启「每日自动补充」后，跨日且事件池至少有两个空位、魔物池与市场池未满时自动请求一次；生成中不会重复触发。
- 设置 → 内容池可调整三池上限并手动移除条目；池满时生成按钮会停止。生成的事件、魔物与候选者都可以在内容池里单独删除。

浏览器直连会把密钥暴露给页面脚本，只适合本地原型验证；正式部署应改为服务端代理。模型文本不能直接修改资源、战斗结果或执行页面代码。


内容生成的设计边界记录在 `tasks/combat-plan.md`，第三版扩展记录在 `tasks/expansion-plan-3.md`，第四版市场/势力/侵蚀方案与实施说明记录在 `tasks/plan-v4.md`：模型只填模板与文案，数值由本地分配器计算，内容包需通过 schema、预算、引用、长度与安全检查后才能进入游戏；战斗结果始终由规则引擎结算。

## 测试

```sh
npm test
npm run build
```

先开启 `http://127.0.0.1:5173` 的预览，再在另一个终端运行：

```sh
npm run test:browser
```

浏览器测试使用已安装的 Google Chrome；需要系统存在 Chrome。可通过环境变量 `PROTOTYPE_URL` 更改验收地址。测试会清空测试浏览器上下文中的演示存档，不影响其他浏览器的用户数据。截图和结果写入 `artifacts/`，不纳入版本控制。

已验收桌面及 1024 / 768 / 390 / 320 宽度布局、唯一交互 ID、拖动与点击派遣、契约成长、基地议事与远行、市场四标签与自定义登记、断药禁派与 Boss 横幅、退休区远程联络、存档恢复、模态焦点和无控制台错误。构建及详细审查记录见 `tasks/review.md`。

## 视觉与性能

React 19、TypeScript 严格模式、Vite 7；Lucide 线性图标，无 emoji。中文展示标题使用本地 Noto Serif SC 子集，数据使用本地 Space Grotesk 子集，中文界面使用系统现代无衬线字体。字体说明见 `public/fonts/NOTICE.md`。SVG 资产均在本地，运行时无外部图像/字体下载；不引入沉重的地图或图表引擎。保留系统 reduced-motion 支持与手动减少动画开关。

当前回归规模：41 项状态测试、26 组浏览器流程。浏览器验收覆盖「导入立绘 → 使魔逐字段补全 → 未确认不落库」「只导入立绘 → 继续手动填写 → 登记并加入名册」「导出契约卡 → 清空存档 → 新游戏导入 → 重复导入被拒绝」。
