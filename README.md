# 夜糖事务所

黑色、雾白与蔷薇粉的魔法少女经营游戏前端原型。以原创等距夜城地图为核心，包含六位魔法少女立绘、派遣与经营流程，以及为未来 LLM 叙事设计的角色对话界面。

**仅前端。没有后端、模型请求、账号、支付或云端存储。** 剧情由本地关键词/脚本响应演示，界面有明确标识。

## 运行

建议 Node.js 22.18+ 或 24+，使用 npm。

```sh
npm ci
npm run dev -- --port 5173 --strictPort
```

打开终端打印的本地地址。生产预览：

```sh
npm run build
npm run preview -- --port 5173 --strictPort
```

浏览器不能通过双击 HTML 正确运行 Vite 的模块和绝对路径资产；请使用开发/静态预览服务。部署到域名根路径即可，不需要业务服务端。

## 可体验的内容

- **城市派遣**：地图/列表切换、任务筛选和缩放；悬停角色显示简报；拖动角色到任务点，或点击任务后选择角色；确认派遣、推进时间、完成委托并结算资源。低血量、疲劳、忙碌及重复派遣均有约束和内部提示。
- **人物档案**：状态概览、魔法能力、心愿与羁绊；治疗、休息、交谈和安排派遣。标签页支持方向键、Home、End；弹窗支持 Escape 和焦点回归。
- **灯下私语**：自由输入、快捷话题、角色立绘、聊天历史、羁绊和场景记忆面板。每条输入最多 500 字，每位角色保留最近 60 条消息，日羁绊增长有限制。
- **基地**：会客厅、医务室、宿舍、观星台平面图；显示在场成员与位置；房间详情、交谈和扩建。扩建宿舍增加契约席位，其他设施扩建提升空间容量，明确展示演示效果边界。
- **市场**：候选契约者筛选、搜索、完整档案及签约确认；资金和基地容量联动。
- **记录**：收入、支出、声望折线图；时间范围、键盘可访问的数据点、日志分类和分页。跨午夜结算按行动的实际完成时刻归日。
- **辅助功能**：内部通知、设置、操作手册、减少动画、存档导出、双重确认重置；每 12 秒自动推进 5 分钟或手动推进 30 分钟。

## 存档与演示边界

数据仅保存于当前浏览器、当前站点的 localStorage（`night-sugar-office:v1`）。刷新可恢复，清除站点数据会丢失；隐私模式/存储不可写时可继续游玩，但无法保证刷新后恢复。导出为 JSON 备份，**本版没有导入界面**。损坏或关系不一致的本地存档自动回退到初始演示状态。

初始数据为第 14 日夜班，内置 5 项任务、4 位在职角色、2 位可招募角色和 4 个房间。任务是一次性演示内容，完成后不会自动刷新；可在设置中重置体验。契合度是选人参考指标，演示版不执行随机战斗，时间结束即完成委托。

## 代码结构与未来 LLM 扩展

- `src/game.ts` / `src/types.ts`：纯函数行动规则、状态模型、数据与恢复校验。
- `src/App.tsx`：页面导航、弹窗编排、持久化、时间与通知。
- `src/components/`：派遣沙盘、角色名单、任务详情、档案、对话与辅助弹窗。
- `src/views/`：基地、市场和经营记录。
- `public/art/`：本地原创 SVG 城市和角色；`public/fonts/`：本地子集字体。
- `tests/`：状态单测与真实浏览器交互验收。

未来接入模型时，可将 `src/game.ts` 的本地 `response` 逻辑替换成独立叙事适配层，输入角色身份、生命/疲劳/羁绊、房间、当前时间和历史消息。保持界面与行动规则分离；模型文本不应直接取得修改资源或执行浏览器代码的权限。本版没有实现、调用或模拟任何远程接口，也没有 API Key 输入。

## 测试

```sh
npm test
npm run build
```

先开启 `http://127.0.0.1:5173` 的预览，再在另一个终端运行：

```sh
npm run test:browser
```

浏览器测试使用已安装的 Google Chrome；需要系统存在 Chrome。可通过环境变量 `PROTOTYPE_URL` 更改验收地址。测试会清空测试浏览器上下文中的演示存档，不影响其他浏览器的用户数据。截图和结果写入 `artifacts/`，不纳入版本控制。

已验收桌面及 1024 / 768 / 390 / 320 宽度布局、唯一交互 ID、拖动与点击派遣、存档恢复、模态焦点和无控制台错误。构建及详细审查记录见 `tasks/review.md`。

## 视觉与性能

React 19、TypeScript 严格模式、Vite 7；Lucide 线性图标，无 emoji。中文展示标题使用本地 Noto Serif SC 子集，数据使用本地 Space Grotesk 子集，中文界面使用系统现代无衬线字体。字体说明见 `public/fonts/NOTICE.md`。SVG 资产均在本地，运行时无外部图像/字体下载；不引入沉重的地图或图表引擎。保留系统 reduced-motion 支持与手动减少动画开关。
