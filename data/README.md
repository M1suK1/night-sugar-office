# 本地文件

这两个目录是「默认本地路径」：导出的存档和契约卡会直接落在这里，卡库扫描与存档位读取也默认指过来。

- `saves/` —— 「设置 → 导出当前存档」写进这里；「存档位 → 项目目录里的存档」列的就是这里的文件。
- `cards/` —— 「导出卡片」写进这里；「契约卡库 → 扫描并导入」默认扫的就是这里。

只有用 `npm run dev`、`npm run preview` 或 `node scripts/serve.mjs` 起的站点才有这套本地接口（见 `scripts/local-files.mjs`）。部署成纯静态站点时没有接口，程序会退回浏览器下载与「选择文件夹」。

目录本身进版本库（留了这个说明文件），里面的 `.json` 被 `.gitignore` 排除，不会把你的存档和卡带上 git。
